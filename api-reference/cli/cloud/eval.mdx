The `eval` command group runs [Pipecat eval scenarios](/pipecat/evals/overview) against an agent deployed on Pipecat Cloud. For concepts, scenario examples, and the equivalent API calls, see the [Evals guide](/pipecat-cloud/guides/evals).

<Warning>
  A synthetic run starts real sessions of your agent, and the agent calls its
  real tools. Use test credentials or a staging deployment.
</Warning>

## run

Create an eval run from a scenario file.

**Usage:**

```shell
pipecat cloud eval run [ARGS] [OPTIONS]
```

**Arguments:**

<ParamField path="agent" type="string" required>
  Name of the deployed agent to run against.
</ParamField>

<ParamField path="scenario_file" type="path" required>
  The scenario YAML file to run.
</ParamField>

**Options:**

<ParamField path="--scenario" type="string">
  The scenario to run, when the file holds more than one.
</ParamField>

<ParamField path="--session" type="string">
  ID of an ended session of the agent. The run is a session run, which judges
  that session's conversation. Without it, the run is synthetic.
</ParamField>

<ParamField path="--param" type="string">
  A synthetic run's setting as `KEY=VALUE`. Repeat the option for several. Not
  allowed on a session run.
</ParamField>

<ParamField path="--deadline" type="integer">
  Seconds the run may take from its creation. A synthetic run takes at least 90
  and defaults to 1800. A session run takes 240 to 1800 and defaults to 600.
</ParamField>

<ParamField path="--root" type="path">
  Directory the scenario's files are read from. Defaults to the scenario file's
  directory. The files under it that the scenario can include are sent with the
  run.
</ParamField>

<ParamField path="--wait" type="boolean" default="false">
  Wait for the run to end, then print its verdict and reason.
</ParamField>

<ParamField path="--organization / -o" type="string">
  Organization to run in. If not provided, uses the current organization from
  your configuration.
</ParamField>

<ParamField path="--json" type="boolean" default="false">
  Print the run as JSON.
</ParamField>

The command prints the run's ID and status. It refuses a bundle over the API's
size limit before it sends anything.

```shell
pipecat cloud eval run my-agent scenarios/greeting.yaml --scenario capital_question --wait
```

### Exit codes

With `--wait`, the exit code is the verdict:

| Code | Meaning                                                    |
| ---- | ---------------------------------------------------------- |
| `0`  | The verdict is `passed`.                                   |
| `1`  | The verdict is `failed`.                                   |
| `2`  | The run ended without a verdict, a cancelled run included. |
| `3`  | An API or usage error.                                     |

Without `--wait`, `0` means the API accepted the request.

Pressing Ctrl-C while waiting stops the wait. It does not cancel the run, and
the CLI prints the [`cancel`](#cancel) command that does.

## status

Show a run, and optionally wait for it to end.

**Usage:**

```shell
pipecat cloud eval status [ARGS] [OPTIONS]
```

**Arguments:**

<ParamField path="run_id" type="string" required>
  ID of the run.
</ParamField>

**Options:**

<ParamField path="--agent" type="string" required>
  Name of the agent the run belongs to.
</ParamField>

<ParamField path="--wait" type="boolean" default="false">
  Wait for the run to end. The [exit codes](#exit-codes) apply.
</ParamField>

<ParamField path="--organization / -o" type="string">
  Organization to query. If not provided, uses the current organization from
  your configuration.
</ParamField>

<ParamField path="--json" type="boolean" default="false">
  Print the run as JSON.
</ParamField>

## list

List an agent's eval runs, newest first.

**Usage:**

```shell
pipecat cloud eval list [ARGS] [OPTIONS]
```

**Arguments:**

<ParamField path="agent" type="string" required>
  Name of the agent.
</ParamField>

**Options:**

<ParamField path="--limit" type="integer">
  Maximum number of runs to show.
</ParamField>

<ParamField path="--organization / -o" type="string">
  Organization to query. If not provided, uses the current organization from
  your configuration.
</ParamField>

<ParamField path="--json" type="boolean" default="false">
  Print the runs as JSON.
</ParamField>

## cancel

Ask for a run to stop. A queued run is cancelled at once. A running run stops
shortly after, and a session it already started stays started. Cancelling a
run that finished returns an error.

**Usage:**

```shell
pipecat cloud eval cancel [ARGS] [OPTIONS]
```

**Arguments:**

<ParamField path="run_id" type="string" required>
  ID of the run.
</ParamField>

**Options:**

<ParamField path="--agent" type="string" required>
  Name of the agent the run belongs to.
</ParamField>

<ParamField path="--organization / -o" type="string">
  Organization to run in. If not provided, uses the current organization from
  your configuration.
</ParamField>

<ParamField path="--json" type="boolean" default="false">
  Print the run as JSON.
</ParamField>
