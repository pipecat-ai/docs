`AICTytoObserver` scores the quality of the user's audio with the ai-coustics Tyto model. It analyzes the latest 5-second window in a background thread after every 5 seconds of received audio, and emits each result through `on_analysis_result`. When the call ends, it emits a summary through `on_call_summary`.

To use Tyto, you need an ai-coustics license key. Get started at [ai-coustics.com](https://docs.ai-coustics.com/tutorials/pipecat-quickstart).

## Installation

```bash
uv add "pipecat-ai[aic]"
```

## Configuration

```python
from pipecat.observers.aic_tyto_observer import AICTytoObserver
```

<ParamField path="license_key" type="str" required>
  ai-coustics SDK license key.
</ParamField>

<ParamField path="model_id" type="str | None" default='"tyto-1.1-l-16khz"'>
  Tyto model identifier. Ignored if `model_path` is set. See
  [artifacts.ai-coustics.io](https://artifacts.ai-coustics.io/) for available
  models.
</ParamField>

<ParamField path="model_path" type="Path | None" default="None">
  Path to a local `.aicmodel` file.
</ParamField>

<ParamField path="model_download_dir" type="Path | None" default="None">
  Directory for downloaded models. Defaults to `~/.cache/pipecat/aic-models`.
</ParamField>

<ParamField path="degraded_threshold" type="float" default="0.3">
  `risk_score` value at or above which the summary counts a window as degraded.
  Must be between `0.0` and `1.0`. Calibrate it against the failures you see in
  your application.
</ParamField>

<ParamField path="audio_filter" type="AICFilter | None" default="None">
  The transport's
  [`AICFilter`](/api-reference/server/services/audio-filters/aic-filter). When
  set, the filter feeds the analysis with the audio before enhancement. When
  `None`, the observer analyzes the `InputAudioRawFrame` audio that the input
  transport pushes.
</ParamField>

Raises `ValueError` when neither `model_id` nor `model_path` is set, or when `degraded_threshold` is outside `0.0` to `1.0`.

## Usage

Tyto must score the audio before enhancement. When `AICFilter` is the transport's `audio_in_filter`, pass the same filter as `audio_filter`:

```python
import os

from pipecat.audio.filters.aic_filter import AICFilter
from pipecat.observers.aic_tyto_observer import AICTytoObserver
from pipecat.pipeline.worker import PipelineWorker

aic_filter = AICFilter(license_key=os.getenv("AIC_SDK_LICENSE"), model_id="quail-vf-2.2-l-16khz")
tyto = AICTytoObserver(license_key=os.getenv("AIC_SDK_LICENSE"), audio_filter=aic_filter)

@tyto.event_handler("on_analysis_result")
async def on_analysis_result(observer, scores, audio_secs):
    logger.info(f"Risk score {scores.risk_score:.2f} at {audio_secs:.0f}s")

@tyto.event_handler("on_call_summary")
async def on_call_summary(observer, summary):
    logger.info(f"Mean risk score: {summary.mean.risk_score}")

worker = PipelineWorker(pipeline, observers=[tyto])
```

## Event Handlers

| Event                | Description                                                                                                                               |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| `on_analysis_result` | A window was analyzed. Receives `scores` (`AICAudioQualityScores`) and `audio_secs` (`float`), the seconds of user audio received so far. |
| `on_call_summary`    | The call ended. Receives `summary` (`AICAudioQualitySummary`). Not emitted when no window was analyzed.                                   |

## AICAudioQualityScores

All scores are in the range `0.0` to `1.0`. A higher value means more problematic audio.

| Field                | Type    | Description                                                                                     |
| -------------------- | ------- | ----------------------------------------------------------------------------------------------- |
| `risk_score`         | `float` | Likelihood that downstream models (STT, VAD, turn-taking, speech-to-speech) fail on this audio. |
| `noise`              | `float` | Ambient or environmental noise.                                                                 |
| `speaker_reverb`     | `float` | Speaker distance and reverberation.                                                             |
| `speaker_loudness`   | `float` | Level of the main speaker. A neutral level, not a degradation.                                  |
| `interfering_speech` | `float` | Speech from other speakers, live or from a device.                                              |
| `packet_loss`        | `float` | Dropouts or discontinuities in the stream.                                                      |
| `codec_degradation`  | `float` | Artifacts from lossy speech codecs.                                                             |

## AICAudioQualitySummary

| Field                | Type                    | Description                                                                                                                                                |
| -------------------- | ----------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `windows`            | `int`                   | Number of analyzed windows.                                                                                                                                |
| `mean`               | `AICAudioQualityScores` | Mean of each score over all windows.                                                                                                                       |
| `p95`                | `AICAudioQualityScores` | 95th percentile of each score over all windows.                                                                                                            |
| `max`                | `AICAudioQualityScores` | Maximum of each score over all windows.                                                                                                                    |
| `degraded_threshold` | `float`                 | `risk_score` value at or above which a window counts as degraded.                                                                                          |
| `degraded_fraction`  | `float`                 | Fraction of windows that are degraded.                                                                                                                     |
| `dominant_dimension` | `str`                   | Name of the score with the highest mean, excluding `risk_score` and `speaker_loudness`. It shows the largest degradation, not the cause of the risk score. |

## Notes

- **First result**: The first analysis waits for a full 5-second window, so calls with less than 5 seconds of user audio emit no results.
- **Model load failure**: If the model fails to load, the observer logs an error and the call continues without analysis.
- **Analysis failure**: If an analysis fails, the observer logs an error and stops analyzing for the rest of the call.
- **Filter initialization**: When `audio_filter` is set and the filter fails to initialize, it passes audio through unenhanced and the observer analyzes nothing.
