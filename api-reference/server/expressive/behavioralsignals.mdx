## Overview

`BehavioralSignalsPerceptionService` is a perception producer for [expressive conversation](/api-reference/server/expressive/overview). It streams the user's voice to the [Behavioral Signals](https://behavioralsignals.com/) API and sets per-utterance estimates of expressed emotion, strength, positivity, hesitation, engagement and speaking rate, each with a probability for every class, as the `perception` of each user turn's transcriptions. The LLM reads it with the user's words. Outputs are probabilistic estimates of signals expressed in speech, not determinations of what a person feels, intends or believes.

It can run with [`PipecatToneReader`](/api-reference/server/expressive/pipecat-tone#pipecattonereader), which reads the words: it adds its reading to the one a transcription already carries.

## Installation

This is a community-maintained package distributed separately from `pipecat-ai`:

```bash
uv add pipecat-behavioralsignals
```

## Prerequisites

- A Behavioral Signals account, with a client ID (CID) and an API key from the [Behavioral Signals portal](https://portal.behavioralsignals.com/).
- Set them as environment variables, or pass them to the service:

```bash
export BEHAVIORALSIGNALS_CID=...
export BEHAVIORALSIGNALS_API_KEY=...
```

The service streams all of the user's input audio for the whole call, and streaming is billed by the minute.

## Usage

Put the service right after your STT service, and turn on expressive conversation:

```python
from pipecat.pipeline.pipeline import Pipeline
from pipecat.pipeline.worker import PipelineParams, PipelineWorker

from pipecat_behavioralsignals import BehavioralSignalsPerceptionService

pipeline = Pipeline([
    transport.input(),
    stt,
    BehavioralSignalsPerceptionService(),
    user_aggregator,
    llm,
    tts,
    transport.output(),
    assistant_aggregator,
])

worker = PipelineWorker(pipeline, params=PipelineParams(enable_expressive_conversation=True))
```

The service reads the audio the STT service passes on, so keep the STT service's default `audio_passthrough=True`. Each user message then starts with the reading:

```
([voice_emotion angry=0.71, neutral=0.20, sad=0.06, happy=0.03],[positivity negative=0.72, neutral=0.20, positive=0.08],[strength strong=0.64, neutral=0.30, weak=0.06],[speaking_rate fast=0.50, normal=0.40, slow=0.10],[hesitation no=0.80, yes=0.20],[engagement engaged=0.55, neutral=0.35, withdrawn=0.10],[intensity value=0.61]) I already told you, I was charged twice.
```

The signals are `voice_emotion`, `strength`, `positivity`, `speaking_rate`, `hesitation`, `engagement` and `intensity`. See the [repository](https://github.com/BehavioralSignalTechnologies/pipecat-behavioralsignals#what-the-llm-sees) for what each reads and how a reading is matched to a turn.
