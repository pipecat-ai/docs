## Overview

`RimeRealtimeLLMService` runs one Rime Prism speech-to-speech conversation. It supports tools (including intermediate results), runtime settings updates, Prism tool fillers, speech speed, interruption rules, and token usage metrics. Use it with `LLMContextAggregatorPair` and any transport.

## Installation

```bash
uv add "pipecat-ai[rime-realtime]"
```

The extra requires `rimelabs-sdk >= 0.1.0a31`.

## Prerequisites

1. **Rime account**: Sign up with Rime and create an API key.
2. **Environment variable**: Set `RIME_API_KEY`. The Rime client reads it when you don't pass `client`.

## Configuration

```python
from pipecat.services.rime.realtime.llm import RimeRealtimeLLMService
```

<ParamField path="client" type="rimelabs_sdk.Rime | None" default="None">
  Rime SDK client you own. When `None`, the service creates one. An injected
  client is not closed when the service stops.
</ParamField>

<ParamField path="endpoint" type="str | None" default="None">
  Prism WebSocket endpoint. When `None`, the SDK default is used.
</ParamField>

<ParamField path="settings" type="RimeRealtimeLLMService.Settings" default="None">
  Initial settings and tools. See [Settings](#settings) below.
</ParamField>

<ParamField
  path="turn_detection"
  type="rimelabs_sdk.realtime.TurnDetection | None"
  default="None"
>
  Server turn detection for the opening, such as eagerness and the end-of-turn
  silence floor. Its interruption rules (`interrupt_min_words`,
  `interrupt_phrases`, `acknowledgment_phrases`) may instead be set in
  `settings`. Setting the same rule in both raises `ValueError`.
</ParamField>

<ParamField
  path="timeouts"
  type="rimelabs_sdk.realtime.RealtimeTimeouts | None"
  default="None"
>
  Connection, readiness, and acknowledgment limits. When `None`, the SDK
  defaults are used.
</ParamField>

<ParamField path="request_id" type="str | None" default="None">
  Correlation ID to request from Rime for this conversation.
</ParamField>

<ParamField path="startup" type="RimeStartupParams | None" default="None">
  Retry policy for opening the conversation: `max_retries` (default 3, 0–10),
  `retry_interval` (default 2 seconds), `attempt_timeout` (default 30 seconds),
  and `total_timeout` (default 60 seconds).
</ParamField>

<ParamField path="playback" type='Literal["estimated", "discard"]' default='"estimated"'>
  `"estimated"` plays the output audio normally. `"discard"` drops all output
  audio and reports it to Prism as unplayed.
</ParamField>

### Settings

Runtime-configurable settings passed via the `settings` constructor argument using `RimeRealtimeLLMService.Settings(...)`. These can be updated mid-conversation with `LLMUpdateSettingsFrame`. See [Service Settings](/pipecat/fundamentals/service-settings) for details.

| Parameter                | Type                       | Default   | Description                                                                                                                                                      |
| ------------------------ | -------------------------- | --------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `model`                  | `str`                      | `"prism"` | Must be `"prism"`. _(Inherited from base settings.)_                                                                                                             |
| `system_instruction`     | `str`                      | `None`    | System instruction. _(Inherited from base settings.)_                                                                                                            |
| `tools`                  | `ToolsSchema \| list`      | `None`    | Tools advertised to Prism. An empty list removes all tools.                                                                                                      |
| `voice`                  | `str \| None`              | `None`    | Prism voice. `None` uses the server default.                                                                                                                     |
| `interrupt_on_speech`    | `bool`                     | `True`    | Whether Prism interrupts its own reply when it hears the user.                                                                                                   |
| `tool_fillers`           | `dict[str, PrismFiller]`   | `{}`      | Filler Prism speaks while a tool runs, keyed by tool name. Each key must name an advertised tool and each value must be a `rimelabs_sdk.realtime.PrismFiller`.     |
| `speed`                  | `float \| None`            | `None`    | Speech speed from 0.85 to 1.3. `None` uses the server default.                                                                                                   |
| `interrupt_min_words`    | `int \| None`              | `None`    | Words, from 1 to 10, the user says over a reply before Prism interrupts it. `None` uses the server default.                                                     |
| `interrupt_phrases`      | `list[str] \| None`        | `None`    | Phrases that interrupt a reply regardless of `interrupt_min_words`. An empty list clears them.                                                                   |
| `acknowledgment_phrases` | `list[str] \| None`        | `None`    | Phrases, such as "uh huh", that don't interrupt a reply. An empty list clears them.                                                                              |
| `truncation`             | `rimelabs_sdk.realtime.Truncation \| None` | `None` | History capacity policy.                                                                                                                              |
| `response_metadata`      | `dict[str, str] \| None`   | `None`    | Labels applied to responses.                                                                                                                                     |

The constructor raises `ValueError` for an invalid value, such as a `speed` outside 0.85–1.3.

## Usage

### Basic Setup

```python
from pipecat.services.rime.realtime.llm import RimeRealtimeLLMService

llm = RimeRealtimeLLMService(
    settings=RimeRealtimeLLMService.Settings(
        system_instruction="You are a helpful voice assistant.",
        speed=1.1,
    ),
)
```

### With Interruption Rules and Tool Fillers

```python
from rimelabs_sdk.realtime import PrismFiller

llm = RimeRealtimeLLMService(
    settings=RimeRealtimeLLMService.Settings(
        system_instruction="You are a billing assistant.",
        tools=tools,
        tool_fillers={
            "lookup_invoice": PrismFiller(type="text", text="Checking your invoice."),
        },
        interrupt_min_words=3,
        interrupt_phrases=["stop", "wait"],
        acknowledgment_phrases=["uh huh", "okay"],
    ),
)
```

### Updating Settings at Runtime

```python
from pipecat.frames.frames import LLMUpdateSettingsFrame

await worker.queue_frame(
    LLMUpdateSettingsFrame(
        delta=RimeRealtimeLLMService.Settings(
            system_instruction="You are now a refunds specialist.",
            speed=1.0,
        )
    )
)
```

### Asking for a Reply

To have the bot speak mid-conversation, queue an `LLMMessagesAppendFrame` with `run_llm=True`:

```python
from pipecat.frames.frames import LLMMessagesAppendFrame

await worker.queue_frame(
    LLMMessagesAppendFrame(
        [{"role": "user", "content": "Greet the user."}], run_llm=True
    )
)
```

## Properties

| Property       | Type                | Description                                                          |
| -------------- | ------------------- | -------------------------------------------------------------------- |
| `session_info` | `SessionInfo \| None` | Acknowledged session information, including the provider request ID. |

## Notes

- **Context**: The first context frame opens the conversation with the context's messages and starts a reply. After that, the service only appends to Prism history: replacing context messages doesn't change it, and `LLMRunFrame` starts no reply. Use `LLMMessagesAppendFrame(run_llm=True)` instead.
- **One conversation per instance**: There is no automatic reconnect or replay. After a failure, start a fresh instance with valid, completed history.
- **Turn detection**: Prism detects turns on the server, so the service uses external user turn strategies.
- **Async tools**: Functions registered with `cancel_on_interruption=False` are supported. Intermediate results (`is_final=False`) are added to Prism history beside the open call, and only the final result answers it. A result that arrives after its response round closed triggers a reply that reports it.
- **Playback**: Playback positions are estimates, and completion receipts are not sent.
- **Metrics**: Emits turn-to-first-output metrics and token usage.

## Event Handlers

| Event                | Parameters | Description                                            |
| -------------------- | ---------- | ------------------------------------------------------ |
| `on_session_updated` | `info`     | Called when Prism acknowledges session information     |
| `on_rime_event`      | `event`    | Called for SDK events, including provider diagnostics  |

```python
@llm.event_handler("on_session_updated")
async def on_session_updated(service, info):
    print(f"Prism session: {info}")
```
