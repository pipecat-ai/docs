## Overview

`ZoomAIRealtimeLLMService` provides speech-to-speech conversation with the [Voice Agent](https://developers.zoom.us/docs/ai-services/voice-agent/live-mode/) from Zoom AI Services. The Voice Agent runs the whole voice loop on Zoom's side: turn detection, speech recognition, the model, and speech synthesis. The service replaces STT, the LLM, and TTS in a pipeline, and supports function calling, interruptions, and transcripts like [OpenAI Realtime](/api-reference/server/services/s2s/openai). The Voice Agent detects turns and handles barge-in itself, so the pipeline needs no VAD analyzer.


## Prerequisites

### Required Environment Variables

- `ZOOM_AI_API_KEY`: Your Zoom AI Services API key

## Configuration

### ZoomAIRealtimeLLMService

<ParamField path="api_key" type="str" required>
  Zoom AI Services API key. It is sent on every connection and reconnect, so it
  must stay valid for as long as the service runs.
</ParamField>

<ParamField
  path="base_url"
  type="str"
  default="wss://api.zoom.us/v2/ws/aiservices/voice-agent/live"
>
  Voice Agent WebSocket URL.
</ParamField>

<ParamField
  path="settings"
  type="ZoomAIRealtimeLLMService.Settings"
  default="None"
>
  Runtime-configurable settings. See [Settings](#settings) below.
</ParamField>

### Settings

Runtime-configurable settings passed via the `settings` constructor argument using `ZoomAIRealtimeLLMService.Settings(...)`. These can be updated mid-conversation with `LLMUpdateSettingsFrame`. See [Service Settings](/pipecat/fundamentals/service-settings) for details.

| Parameter            | Type                | Default               | Description                                                                                                                                                                                                                                                          |
| -------------------- | ------------------- | --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `model`              | `str`               | `"gemma-4"`           | Model identifier. Names the provider's model when `provider` is set and sets none of its own. Fixed once the session is configured. _(Inherited from base settings.)_                                                                                                |
| `system_instruction` | `str`               | `None`                | System instruction/prompt. _(Inherited from base settings.)_                                                                                                                                                                                                         |
| `session_properties` | `SessionProperties` | `SessionProperties()` | OpenAI Realtime session properties. The service uses `instructions`, `tools`, `tool_choice`, `max_output_tokens`, `reasoning`, and `audio.output.voice` (when `speak` sets no voice).                                                                                 |
| `provider`           | `Provider`          | `None`                | Where the model runs: Zoom's own models (`None`), or your own OpenAI or Anthropic account. Fixed once the session is configured.                                                                                                                                     |
| `listen`             | `Listen`            | `None`                | How the agent listens: the caller's language and custom vocabulary. `None` takes the server's defaults. Fixed once the session is configured.                                                                                                                        |
| `speak`              | `Speak`             | `None`                | How the agent speaks: its voice. `None` takes the server's default voice.                                                                                                                                                                                            |
| `extra`              | `dict`              | `None`                | Voice Agent session fields the service has no setting for, shaped like the `session` of `session.update`. Merged into each session update over the settings above.                                                                                                   |

`provider`, `listen`, and `speak` also accept plain dicts.

### Provider

| Parameter  | Type             | Default  | Description                                                                                                                                         |
| ---------- | ---------------- | -------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| `type`     | `str`            | `"zoom"` | `"zoom"` for a Zoom-hosted model, or `"openai"` / `"anthropic"` to use your own key for that provider's model.                                      |
| `model`    | `str`            | `None`   | Model ID, for example `"gemma-4"`.                                                                                                                  |
| `headers`  | `dict[str, str]` | `None`   | Headers for the provider, such as `{"X-Api-Key": "..."}` with your own provider key. Required for `"openai"` and `"anthropic"`.                     |
| `metadata` | `dict`           | `None`   | The provider model's limits, such as `context_window` and `max_output_tokens`.                                                                      |

### Listen

| Parameter       | Type            | Default | Description                                                                             |
| --------------- | --------------- | ------- | --------------------------------------------------------------------------------------- |
| `transcription` | `Transcription` | `None`  | Speech recognition settings: `language` (for example `"en"`) and `vocabulary`.          |

`Transcription.vocabulary` is a `Vocabulary` whose `phrases` lists names and terms to recognize, such as product names.

### Speak

| Parameter | Type  | Default    | Description                                                                 |
| --------- | ----- | ---------- | --------------------------------------------------------------------------- |
| `voice`   | `str` | `None`    | Voice ID, for example `"jenna"` (the server's default). See the Voice Agent documentation for the list of voices. |

## Usage

### Basic Setup

```python
import os
from pipecat.services.zoom_ai.realtime.llm import ZoomAIRealtimeLLMService

llm = ZoomAIRealtimeLLMService(
    api_key=os.getenv("ZOOM_AI_API_KEY"),
    settings=ZoomAIRealtimeLLMService.Settings(
        system_instruction="You are a helpful assistant.",
    ),
)
```

### With Voice and Vocabulary

```python
from pipecat.services.zoom_ai.realtime.events import (
    Listen,
    Speak,
    Transcription,
    Vocabulary,
)

llm = ZoomAIRealtimeLLMService(
    api_key=os.getenv("ZOOM_AI_API_KEY"),
    settings=ZoomAIRealtimeLLMService.Settings(
        system_instruction="You are a helpful assistant.",
        speak=Speak(voice="jenna"),
        listen=Listen(
            transcription=Transcription(
                language="en",
                vocabulary=Vocabulary(phrases=["Pipecat"]),
            )
        ),
    ),
)
```

### With Your Own Model Provider

```python
from pipecat.services.zoom_ai.realtime.events import Provider

llm = ZoomAIRealtimeLLMService(
    api_key=os.getenv("ZOOM_AI_API_KEY"),
    settings=ZoomAIRealtimeLLMService.Settings(
        model="gpt-4o",
        provider=Provider(
            type="openai",
            headers={"X-Api-Key": os.getenv("OPENAI_API_KEY")},
        ),
    ),
)
```

## Notes

- **Turn detection**: The Voice Agent detects turns, noise, and barge-in itself. None of these is configurable.
- **Settings fixed at connection**: `model`, `provider`, and `listen` are fixed once the session is configured. Updating them mid-conversation logs a warning and applies to the next session. Updates to instructions, tools, and voice take effect immediately.
- **Audio**: Input audio is sent at the pipeline's input sample rate. The agent speaks 16 kHz audio, played at 24 kHz. Audio that arrives while the session is connecting or reconnecting is held (up to the latest three seconds) and sent once the session is ready.
- **Text-only replies**: When the audio output modality is disabled, the agent replies in text only.
- **Reconnection**: If the session ends unexpectedly (the connection closing, or a session reaching its time limit), the service reconnects and restores the conversation. If reconnecting fails, it pushes a permanent error.
- **Errors**: Errors the Voice Agent reports without ending the session are pushed as non-fatal errors. If it rejects the session's settings (an unknown voice, say) or the provider rejects your provider key, the error is permanent.
- **Function call output**: A function call's output is created right after the call in the conversation, where the Voice Agent's model reads it.
