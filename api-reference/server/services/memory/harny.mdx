## Overview

The `pipecat-harny` integration connects [Harny](https://harny.ai) to Pipecat voice pipelines. It ships one `FrameProcessor`: `HarnyMemoryService` sits between the user context aggregator and the LLM service. For each new user turn it recalls dated facts about the person, adds them to the LLM context as one developer message, and saves what the person said in the background.

## Installation

This is a community-maintained package distributed separately from `pipecat-ai`:

```bash
uv add pipecat-harny
```

Requires `pipecat-ai>=1.17.0` and Python 3.10+.

## Prerequisites

You do not need an account first. From the project folder:

```bash
pip install harny
harny init --name "<business>" --about "<what the app does>" --customers "<who its customers are>"
```

That creates the app and saves `HARNY_API_KEY` to `.env` without printing it. Never print, log or commit the key.

## Configuration

### `HarnyMemoryService`

Inserted **after** the user context aggregator and **before** the LLM service.

<ParamField path="user" type="str" required>
  Your own id for the person. The API reads only that person's memory, so one app key can serve every user safely.
</ParamField>

<ParamField path="api_key" type="str" default="None">
  Harny app key (`fsa_`). Falls back to the `HARNY_API_KEY` environment variable.
</ParamField>

<ParamField path="base_url" type="str" default="None">
  Harny API address. Falls back to `HARNY_API_URL`, else `https://api.harny.ai`.
</ParamField>

<ParamField path="level" type="str" default='"medium"'>
  How much evidence to recall: `low`, `medium`, `high` or `extra-high`.
</ParamField>

<ParamField path="limit" type="int" default="None">
  Most facts recalled per turn (1 to 200). Defaults to the API's own default.
</ParamField>

<ParamField path="recall_timeout_secs" type="float" default="2.0">
  How long a turn waits for recall. On timeout the frame goes on without memory.
</ParamField>

<ParamField path="save_user_messages" type="bool" default="True">
  Save what the person says after each turn. The model's replies are never saved.
</ParamField>

<ParamField path="position" type="int" default="1">
  Where in the context messages the recalled facts are inserted.
</ParamField>

## Usage

```python
from pipecat.pipeline.pipeline import Pipeline
from pipecat_harny import HarnyMemoryService

memory = HarnyMemoryService(user="nadia")  # reads HARNY_API_KEY; "nadia" is YOUR id for the person

pipeline = Pipeline([
    transport.input(),
    stt,
    user_aggregator,
    memory,
    llm,
    tts,
    transport.output(),
    assistant_aggregator,
])
```

<Note>
  A memory problem never fails the call. If recall is refused or too slow, the turn goes on without memory and one warning with the error code is logged.
</Note>

## Compatibility

The integration requires `pipecat-ai>=1.17.0` and was tested with Pipecat v1.17.0, through `pipecat.tests.utils.run_test`. Check the [source repository](https://github.com/harny-ai/pipecat-harny) for the latest tested version and changelog.
