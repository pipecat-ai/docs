## Overview

`ChariotTTSService` synthesizes speech using [Chariot](https://chariot.in), which
serves lifelike voices for Indian languages and English.

The service keeps one WebSocket open for the whole conversation, with each bot
turn as its own context, and streams audio while the server is still
generating. Any voice speaks any supported language, so the audio follows the
text rather than the voice, and there is no language parameter to set.

## Installation

```bash
uv add pipecat-chariot
```

## Prerequisites

1. Create an account at [platform.chariot.in](https://platform.chariot.in). New accounts include free credits.
2. Copy an API key from the console and set `CHARIOT_API_KEY`.
3. Optionally pick a voice from `GET https://api.chariot.in/v1/voices`. Without one the service uses a Chariot stock voice.

## Configuration

<ParamField path="api_key" type="str" required>
  Chariot API key.
</ParamField>

<ParamField path="voice_id" type="str" default="None">
  Voice UUID from `GET /v1/voices`. `settings.voice` takes precedence. Defaults
  to a Chariot stock voice.
</ParamField>

<ParamField path="model" type="str" default="chariot-multilingual-v1">
  `chariot-multilingual-v1` or `chariot-v0`. `settings.model` takes precedence.
</ParamField>

<ParamField path="speed" type="float" default="None">
  Speaking rate. Leave unset for the voice as recorded. `settings.speed` takes
  precedence.
</ParamField>

<ParamField path="enable_logging" type="bool" default="None">
  Not sent unless set. Unset or `True`: your workspace's data retention setting
  decides. `False` keeps the generated audio out of storage.
</ParamField>

<ParamField path="sample_rate" type="int" default="44100">
  Chariot streams 44.1 kHz; a mismatch logs a warning.
</ParamField>

### Settings

Pass these through `ChariotTTSService.Settings(...)`. They can also be updated
while the pipeline is running with `TTSUpdateSettingsFrame`.

| Parameter | Type    | Default                   | Description                                                   |
| --------- | ------- | ------------------------- | ------------------------------------------------------------- |
| `voice`   | `str`   | stock voice               | Voice UUID. Applies from the next turn, without reconnecting. |
| `model`   | `str`   | `chariot-multilingual-v1` | Changing it reconnects.                                       |
| `speed`   | `float` | voice as recorded         | Applies from the next turn, without reconnecting.             |

<Note>
  Speaking rates are pre-encoded per voice and per model, so `speed` is one of a
  fixed set rather than a range. `GET /v1/voices` lists what each voice offers
  under each model as `speeds`.
</Note>

## Usage

```python
import os

from pipecat_chariot import ChariotTTSService

tts = ChariotTTSService(
    api_key=os.getenv("CHARIOT_API_KEY"),
    settings=ChariotTTSService.Settings(voice=os.getenv("CHARIOT_VOICE_ID")),
)
```

## Interruptions

When the user barges in, the turn's Chariot context is cancelled: generation
stops at once and the connection stays open, so the next turn starts without a
new handshake. Nothing needs configuring.

## Compatibility

Tested with Pipecat v1.15.0 (`pipecat-ai>=1.13,<2`). See the
[changelog](https://github.com/Chariot-AI/pipecat-chariot/blob/main/CHANGELOG.md)
for updates.
