## Overview

`DeepdubTTSService` generates speech with [Deepdub](https://deepdub.ai/)'s emotional
TTS. It extends Pipecat's `WebsocketTTSService`: LLM tokens stream to Deepdub as they
arrive, and audio streams back over the same connection as `TTSAudioRawFrame`s.

An interruption cancels the reply on the open connection instead of reconnecting, and
audio from the canceled reply is dropped. A reply that starts while another is still
speaking, such as a `TTSSpeakFrame`, waits for it to finish. Voice, locale and model
changes apply to the open connection from the next text.

The same package provides [Deepdub speech-to-text](/api-reference/server/services/stt/deepdub).

## Installation

This is a community-maintained package distributed separately from `pipecat-ai`:

```bash
uv add pipecat-deepdub
```

## Prerequisites

### Deepdub Account Setup

Before using the Deepdub TTS service, you need:

1. **Deepdub Account**: Sign up at [Deepdub](https://deepdub.ai/)
2. **API Key**: Obtain your API key from your Deepdub account

### Required Environment Variables

- `DEEPDUB_API_KEY`: Your Deepdub API key

## Configuration

<ParamField path="api_key" type="str" required>
  Deepdub API key.
</ParamField>

<ParamField path="url" type="str" default="wss://wss.deepdub.ai/ws">
  Streaming endpoint. Use `wss://wss.eu.deepdub.ai/ws` to process data in the
  EU.
</ParamField>

<ParamField path="sample_rate" type="int" default="None">
  Output sample rate in Hz. If `None`, uses the pipeline's output rate. Deepdub
  streams 8000, 16000, 22050, 24000, 32000, 36000, 44100 or 48000 Hz; other
  rates are resampled from the next one up.
</ParamField>

<ParamField path="enable_logging" type="bool" default="None">
  Set to `False` to keep this session's text out of Deepdub's server-side logs.
  `None` leaves Deepdub's default (on).
</ParamField>

<ParamField path="turn_timeout" type="float" default="10.0">
  Seconds to wait for audio after a reply is complete before reporting an error.
</ParamField>

<ParamField path="settings" type="DeepdubTTSService.Settings" default="None">
  Runtime-updatable settings. See [Settings](#settings) below.
</ParamField>

### Settings

Runtime-configurable settings passed via the `settings` constructor argument using
`DeepdubTTSService.Settings(...)`. They can be updated mid-conversation with
`TTSUpdateSettingsFrame`, without reconnecting.

| Parameter       | Type           | Default                                  | Description                                                                       |
| --------------- | -------------- | ---------------------------------------- | --------------------------------------------------------------------------------- |
| `model`         | `str`          | `"dd-etts-4.0"`                          | Deepdub TTS model.                                                                |
| `voice`         | `str`          | `"b2abb241-ac92-48bf-a890-fec03f43e209"` | Voice prompt ID.                                                                  |
| `language`      | `str`          | `"en-US"`                                | Locale to speak, such as `"he-IL"`. A Pipecat `Language` works too.               |
| `target_gender` | `str \| None`  | `None`                                   | `"male"` or `"female"`, for language-specific handling such as Hebrew diacritics. |
| `accept_emojis` | `bool \| None` | `None`                                   | Whether flag and emotion emojis switch locale or emotion instead of being spoken. |

## Usage

```python
import os

from pipecat_deepdub import DeepdubTTSService

tts = DeepdubTTSService(
    api_key=os.getenv("DEEPDUB_API_KEY"),
    settings=DeepdubTTSService.Settings(
        voice="b2abb241-ac92-48bf-a890-fec03f43e209",
        language="en-US",
    ),
)
```

### Switching Language Mid-Conversation

```python
from pipecat.frames.frames import TTSUpdateSettingsFrame

await worker.queue_frame(
    TTSUpdateSettingsFrame(delta=DeepdubTTSService.Settings(language="he-IL"))
)
```

## Notes

- **Audio format**: Deepdub streams 16-bit mono PCM.
- **Migrating from `pipecat-deepdub-tts`**: Install `pipecat-deepdub` and import from
  `pipecat_deepdub`. `voice_id`, `model` and `params` became `settings`. The
  `temperature`, `variance`, `tempo`, `prompt_boost` and accent options are gone,
  because Deepdub's streaming endpoint ignores them.

## Compatibility

Tested with Pipecat 1.17.0. See the [source
repository](https://github.com/deepdub-ai/pipecat) for the latest tested version and
changelog.
