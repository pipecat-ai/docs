## Overview

ConvoZen's Ragini models synthesize speech in nine Indian languages.
`ConvozenHttpTTSService` streams audio back as it is generated, which keeps
time-to-first-audio down in a conversation.

## Installation

To use ConvoZen services, install the required dependency:

```bash
uv add "pipecat-ai[convozen]"
```

## Prerequisites

### ConvoZen Account Setup

Before using ConvoZen TTS, you need:

1. **ConvoZen Account**: Sign up at [ConvoZen](https://convozen.ai/)
2. **API Key**: Generate an API key from your account dashboard

### Required Environment Variables

- `CONVOZEN_API_KEY`: Your ConvoZen API key for authentication

## Configuration

<ParamField path="api_key" type="str" required>
  ConvoZen API key for authentication.
</ParamField>

<ParamField path="aiohttp_session" type="aiohttp.ClientSession" required>
  The bot's shared aiohttp session, used for every request to ConvoZen. Create
  one per bot with `async with aiohttp.ClientSession() as session:` and pass the
  same session to each HTTP service, so connections are pooled and closed once.
</ParamField>

<ParamField path="model" type="str" default="ragini-v1">
  Ragini model to use. Allowed values: `"ragini-v1"`, `"ragini-lite"`.
</ParamField>

<ParamField
  path="base_url"
  type="str"
  default="https://voice.convozen.ai/sdk-models/developer-api/api"
>
  API base URL. Override to reach a self-hosted deployment.
</ParamField>

<ParamField path="sample_rate" type="int" default="None">
  Output sample rate in Hz. `None` uses the model's native rate: 24000 for
  `ragini-v1`, 22050 for `ragini-lite`.
</ParamField>

<ParamField
  path="settings"
  type="ConvozenHttpTTSService.Settings"
  default="None"
>
  Runtime-configurable settings for the TTS service. See [Settings](#settings)
  below.
</ParamField>

### Settings

Runtime-configurable settings passed via the `settings` constructor argument using `ConvozenHttpTTSService.Settings(...)`. These can be updated mid-conversation with `TTSUpdateSettingsFrame`. See [Service Settings](/pipecat/fundamentals/service-settings) for details.

| Parameter  | Type              | Default   | Description                                                   |
| ---------- | ----------------- | --------- | ------------------------------------------------------------- |
| `model`    | `str`             | `None`    | TTS model identifier. _(Inherited from base TTS settings.)_   |
| `voice`    | `str`             | `"roohi"` | Voice identifier. _(Inherited from base TTS settings.)_       |
| `language` | `Language \| str` | `None`    | Language for synthesis. _(Inherited from base TTS settings.)_ |
| `speed`    | `float`           | `1.0`     | Speaking rate multiplier; `1.0` is the natural pace.          |

## Usage

### Basic Setup

```python
import aiohttp
from pipecat.services.convozen.tts import ConvozenHttpTTSService
from pipecat.transcriptions.language import Language

async with aiohttp.ClientSession() as session:
    tts = ConvozenHttpTTSService(
        api_key=os.getenv("CONVOZEN_API_KEY"),
        aiohttp_session=session,
    )
```

### With Voice and Language

```python
tts = ConvozenHttpTTSService(
    api_key=os.getenv("CONVOZEN_API_KEY"),
    aiohttp_session=session,
    settings=ConvozenHttpTTSService.Settings(
        voice="amaya",
        language=Language.HI,
        speed=1.1,
    ),
)
```

## Notes

- **Supported models**: `ragini-v1` (default, 24000 Hz) and `ragini-lite` (22050 Hz).
- **Supported languages**: Bengali (bn), English (en), Gujarati (gu), Hindi (hi), Kannada (kn), Malayalam (ml), Marathi (mr), Tamil (ta), and Telugu (te). Regional variants such as `hi-IN` map to their base code.
- **Voices**: `roohi` (default), `amaya`, `kiyansh`, `neeraj`, `manya`, `nidhi`, `ira`, `trisha`, and `charvi`. Any voice identifier the account has access to is accepted, so voices added server-side work without upgrading Pipecat.
- **Sample rates**: 8000, 16000, 22050 and 24000 Hz are all supported. Leaving `sample_rate` unset asks for the model's native rate and avoids a resampling pass on the server.
- **Output format**: Ragini returns WAV. The service streams the response and strips the container header, resampling to the pipeline's rate when the two differ.
