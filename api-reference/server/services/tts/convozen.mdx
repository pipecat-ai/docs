## Overview

ConvoZen's Ragini 2.0 model synthesizes speech in English, Hindi, Kannada,
Tamil and Telugu. `ConvozenHttpTTSService` streams audio back as it is
generated, which keeps time-to-first-audio down in a conversation.

## Installation

This is a community-maintained package distributed separately from `pipecat-ai`:

```bash
uv add pipecat-convozen
```

## Prerequisites

### ConvoZen Account Setup

Before using ConvoZen TTS, you need:

1. **ConvoZen Account**: Sign up at [ConvoZen](https://convozen.ai/)
2. **API Key**: Generate an API key from your [account dashboard](https://app.convozen.ai/developers/models)

### Required Environment Variables

- `CONVOZEN_API_KEY`: Your ConvoZen API key for authentication

## Configuration

<ParamField path="api_key" type="str" required>
  ConvoZen API key for authentication.
</ParamField>

<ParamField path="aiohttp_session" type="aiohttp.ClientSession" required>
  The bot's shared aiohttp session, used for every request to ConvoZen. Create
  one per bot with `async with aiohttp.ClientSession() as session:` and pass the
  same session to each HTTP service, so connections are pooled and closed once.
</ParamField>

<ParamField path="model" type="str" default="ragini-v2">
  Ragini model to use. `"ragini-v2"` (Ragini 2.0) is currently the only
  supported model.
</ParamField>

<ParamField
  path="base_url"
  type="str"
  default="https://voice.convozen.ai/sdk-models/developer-api/api"
>
  API base URL. Override to reach a self-hosted deployment.
</ParamField>

<ParamField path="sample_rate" type="int" default="None">
  Output sample rate in Hz. `None` uses the pipeline's output rate. Audio is
  resampled from Ragini 2.0's native 48000 Hz.
</ParamField>

<ParamField
  path="settings"
  type="ConvozenHttpTTSService.Settings"
  default="None"
>
  Runtime-configurable settings for the TTS service. See [Settings](#settings)
  below.
</ParamField>

### Settings

Runtime-configurable settings passed via the `settings` constructor argument using `ConvozenHttpTTSService.Settings(...)`. These can be updated mid-conversation with `TTSUpdateSettingsFrame`. See [Service Settings](/pipecat/fundamentals/service-settings) for details.

| Parameter  | Type              | Default     | Description                                                   |
| ---------- | ----------------- | ----------- | ------------------------------------------------------------- |
| `model`    | `str`             | `None`      | TTS model identifier. _(Inherited from base TTS settings.)_   |
| `voice`    | `str`             | `"shrajay"` | Voice identifier. _(Inherited from base TTS settings.)_       |
| `language` | `Language \| str` | `None`      | Language for synthesis. _(Inherited from base TTS settings.)_ |

## Usage

### Basic Setup

```python
import os

import aiohttp
from pipecat_convozen import ConvozenHttpTTSService
from pipecat.transcriptions.language import Language

async with aiohttp.ClientSession() as session:
    tts = ConvozenHttpTTSService(
        api_key=os.getenv("CONVOZEN_API_KEY"),
        aiohttp_session=session,
    )
```

### With Voice and Language

```python
tts = ConvozenHttpTTSService(
    api_key=os.getenv("CONVOZEN_API_KEY"),
    aiohttp_session=session,
    settings=ConvozenHttpTTSService.Settings(
        voice="sherin",
        language=Language.HI,
    ),
)
```

See the [source repository](https://github.com/ConvoZenAI/pipecat-convozen) for a
complete runnable example wiring a transport → STT → LLM → TTS.

## Notes

- **Supported models**: `ragini-v2` (Ragini 2.0, 48000 Hz).
- **Supported languages**: English (en), Hindi (hi), Kannada (kn), Tamil (ta), and Telugu (te). Regional variants such as `hi-IN` map to their base code; other languages are rejected by the API.
- **Voices**: for `en` and `hi`: `shrajay` (default), `siddharth`, `parmi`, `sherin`, `bhavya`, `shreya`. For `kn`, `ta` and `te`: `amaya`, `parmi`, `roohi`, `bhavya`, `shrajay`, `siddharth`. An unknown voice name is not an error — the API returns an arbitrary voice — so check the spelling.
- **Speaking rate**: Ragini 2.0 does not support speed control.
- **Output format**: Ragini returns 48 kHz WAV. The service streams the response, strips the container header, and resamples to the pipeline's rate.
