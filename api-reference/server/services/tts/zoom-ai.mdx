## Overview

`ZoomAIHttpTTSService` provides text-to-speech with the [Text-to-Speech API](https://developers.zoom.us/docs/ai-services/tts/) from Zoom AI Services in Fast mode. Each sentence is one HTTPS request, and its audio streams back in the response, so playback starts before synthesis finishes. The API returns 44.1 kHz audio, which is resampled to the pipeline's output rate. An interruption closes the request, which stops synthesis on the server.

## Installation

To use Zoom AI services, install the required dependency:

```bash
uv add "pipecat-ai[zoom-ai]"
```

## Prerequisites

### Zoom AI Account Setup

Before using Zoom AI TTS, you need:

1. **Zoom AI Services access**: Sign up through [Zoom AI Services](https://www.zoom.ai/)
2. **API key**: Create a Zoom AI Services API key. See [Get credentials](https://developers.zoom.us/docs/ai-services/auth/).

### Required Environment Variables

- `ZOOM_AI_API_KEY`: Your Zoom AI Services API key

## Configuration

### ZoomAIHttpTTSService

<ParamField path="api_key" type="str" required>
  Zoom AI Services API key or JWT.
</ParamField>

<ParamField path="aiohttp_session" type="aiohttp.ClientSession" required>
  Shared aiohttp session for HTTP requests.
</ParamField>

<ParamField
  path="base_url"
  type="str"
  default="https://api.zoom.us/v2/aiservices/tts/synthesize"
>
  Text-to-Speech synthesize endpoint URL. A plaintext `http://` URL to a host
  other than localhost logs a warning, since the API key and text are sent
  unencrypted.
</ParamField>

<ParamField path="sample_rate" type="int | None" default="None">
  Output audio sample rate in Hz. If `None`, uses the pipeline's output sample
  rate.
</ParamField>

<ParamField path="settings" type="ZoomAIHttpTTSService.Settings" default="None">
  Runtime-configurable settings for the TTS service. See [Settings](#settings)
  below.
</ParamField>

### Settings

Runtime-configurable settings passed via the `settings` constructor argument using `ZoomAIHttpTTSService.Settings(...)`. These can be updated mid-conversation with `TTSUpdateSettingsFrame`. See [Service Settings](/pipecat/fundamentals/service-settings) for details.

| Parameter | Type            | Default   | Description                                                                                                                                  |
| --------- | --------------- | --------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| `voice`   | `str`           | `"jenna"` | Zoom TTS voice ID, such as `jenna` or `ava`. See the [list of voices](https://developers.zoom.us/docs/ai-services/tts/#language-and-voices). |
| `speed`   | `float \| None` | `None`    | Speaking rate multiplier, from 0.5 to 2.0. `None` uses the voice's normal rate.                                                              |
| `volume`  | `float \| None` | `None`    | Volume multiplier, greater than 0 and up to 10. `None` uses the voice's normal volume.                                                       |

The API has no language or model field, so `language` and `model` are `None`.

## Usage

### Basic Setup

```python
import os

import aiohttp

from pipecat.services.zoom_ai.tts import ZoomAIHttpTTSService

async with aiohttp.ClientSession() as session:
    tts = ZoomAIHttpTTSService(
        api_key=os.getenv("ZOOM_AI_API_KEY"),
        aiohttp_session=session,
    )
```

### Custom Voice, Speed, and Volume

```python
tts = ZoomAIHttpTTSService(
    api_key=os.getenv("ZOOM_AI_API_KEY"),
    aiohttp_session=session,
    settings=ZoomAIHttpTTSService.Settings(
        voice="ava",
        speed=1.1,
        volume=1.0,
    ),
)
```

### Updating Settings at Runtime

```python
from pipecat.frames.frames import TTSUpdateSettingsFrame
from pipecat.services.zoom_ai.tts import ZoomAITTSSettings

await task.queue_frame(
    TTSUpdateSettingsFrame(delta=ZoomAITTSSettings(voice="ava", speed=1.2))
)
```

## Notes

- **Input length**: One request accepts up to 4000 Unicode code points. Longer text is split at whitespace and sent in several requests.
- **Audio format**: The API returns signed 16-bit mono PCM at 44.1 kHz only.
- **Errors**: Error messages include the `x-zm-trackingid` of the request, which you can give to Zoom support when investigating a failure.
