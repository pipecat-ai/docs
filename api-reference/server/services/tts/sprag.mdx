## Overview

`SpragTTSService` provides real-time text-to-speech synthesis using [Sprag](https://sprag.ai)'s WebSocket API.

## Installation

This is a community-maintained package distributed separately from `pipecat-ai`.

```bash
uv add pipecat-sprag
```

## Prerequisites

### Sprag Account Setup

Before using Sprag TTS, you need:

1. **Sprag Account**: Sign up at [sprag.ai](https://sprag.ai/auth/signup)
2. **API Key**: Generate an API key in the [Sprag app](https://sprag.ai/app/api-keys)

### Required Environment Variables

- `SPRAG_API_KEY`: Your Sprag API key. May be passed directly via the `api_key` constructor argument instead.

## Configuration

<ParamField path="api_key" type="str" default="None">
  Sprag API key. Falls back to the `SPRAG_API_KEY` environment variable.
</ParamField>

<ParamField path="url" type="str" default="wss://api.sprag.ai/v1/audio/speech">
  Sprag streaming speech WebSocket URL.
</ParamField>

<ParamField path="connect_timeout" type="float" default="10.0">
  Session setup timeout in seconds.
</ParamField>

<ParamField path="settings" type="SpragTTSService.Settings" default="None">
  Runtime-configurable settings. See [Settings](#settings) below.
</ParamField>

### Settings

| Parameter | Type  | Default    | Description                                                                                                   |
| --------- | ----- | ---------- | ------------------------------------------------------------------------------------------------------------- |
| `model`   | `str` | `"chorus"` | Sprag speech model.                                                                                           |
| `voice`   | `str` | `"wade"`   | Voice ID: a [preset voice](https://sprag.ai/docs/tts/voices/presets) or a voice created in your organization. |

Changing `model` or `voice` at runtime reconnects the session.

## Usage

```python
from pipecat_sprag.tts import SpragTTSService

tts = SpragTTSService(settings=SpragTTSService.Settings(voice="marin"))
```

```python
pipeline = Pipeline([
    transport.input(),
    stt,
    user_aggregator,
    llm,
    tts,
    transport.output(),
    assistant_aggregator,
])
```

## Compatibility

Tested with Pipecat v1.12.0 (`pipecat-ai>=1.8,<2`). Check the [source repository](https://github.com/sprag-ai/pipecat-sprag) for the latest tested version and changelog.
