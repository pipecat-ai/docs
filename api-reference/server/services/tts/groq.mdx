## Installation

To use Groq services, install the required dependencies:

```bash
uv add "pipecat-ai[groq]"
```

## Prerequisites

### Groq Account Setup

Before using Groq TTS services, you need:

1. **Groq Account**: Sign up at [Groq Console](https://console.groq.com/login)
2. **API Key**: Generate an API key from your account dashboard
3. **Voice Selection**: Choose from available voice models

### Required Environment Variables

- `GROQ_API_KEY`: Your Groq API key for authentication

## Configuration

### GroqTTSService

<ParamField path="api_key" type="str" required>
  Groq API key for authentication.
</ParamField>

<ParamField path="model_name" type="str" default="None" deprecated>
  _Deprecated since 0.0.105, removed in 2.0.0._ Use
  `settings=GroqTTSService.Settings(model=...)` instead.
</ParamField>

<ParamField path="voice_id" type="str" default="None" deprecated>
  _Deprecated since 0.0.105, removed in 2.0.0._ Use
  `settings=GroqTTSService.Settings(voice=...)` instead.
</ParamField>

<ParamField path="output_format" type="str" default="wav">
  Audio output format. Must be `"wav"`: the service decodes each response as
  WAV, so any other format produces an `ErrorFrame` instead of audio.
</ParamField>

<ParamField path="sample_rate" type="int | None" default="None">
  Audio sample rate in Hz. Not sent to Groq: audio frames carry the sample rate
  of the WAV that Groq returns, so this value doesn't change the output audio.
</ParamField>

<ParamField path="params" type="InputParams" default="None" deprecated>
  _Deprecated since 0.0.105, removed in 2.0.0._ Use
  `settings=GroqTTSService.Settings(...)` instead.
</ParamField>

<ParamField path="settings" type="GroqTTSService.Settings" default="None">
  Runtime-configurable settings. See [Settings](#settings) below.
</ParamField>

### Settings

Runtime-configurable settings passed via the `settings` constructor argument using `GroqTTSService.Settings(...)`. These can be updated mid-conversation with `TTSUpdateSettingsFrame`. See [Service Settings](/pipecat/fundamentals/service-settings) for details.

| Parameter  | Type              | Default                           | Description                                                                  |
| ---------- | ----------------- | --------------------------------- | ---------------------------------------------------------------------------- |
| `model`    | `str`             | `"canopylabs/orpheus-v1-english"` | Model identifier. _(Inherited.)_                                             |
| `voice`    | `str`             | `"autumn"`                        | Voice identifier. _(Inherited.)_                                             |
| `language` | `Language \| str` | `"en"`                            | Language used to split text into sentences; not sent to Groq. _(Inherited.)_ |
| `speed`    | `float`           | `1.0`                             | Speech rate control.                                                         |

## Usage

### Basic Setup

```python
import os
from pipecat.services.groq.tts import GroqTTSService

tts = GroqTTSService(
    api_key=os.getenv("GROQ_API_KEY"),
    settings=GroqTTSService.Settings(
        voice="autumn",
    ),
)
```

### With Custom Settings

```python
from pipecat.transcriptions.language import Language

tts = GroqTTSService(
    api_key=os.getenv("GROQ_API_KEY"),
    settings=GroqTTSService.Settings(
        model="canopylabs/orpheus-v1-english",
        voice="autumn",
        language=Language.EN,
    ),
)
```
