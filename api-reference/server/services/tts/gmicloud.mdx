## Overview

`GmicloudHttpTTSService` streams speech from [GMI Cloud](https://www.gmicloud.ai)'s
multimodal inference engine. One service covers the TTS models in GMI Cloud's
catalog: Inworld Realtime TTS, MiniMax speech synthesis, and Resemble AI's
Chatterbox, behind a single request-queue API. The adapter speaks each model
family's request shape and resolves both synchronous and queued responses.

## Installation

This is a community-maintained package distributed separately from `pipecat-ai`:

```bash
uv add pipecat-gmicloud
```

## Prerequisites

### GMI Cloud Account Setup

1. **GMI Cloud account**: sign up at [GMI Cloud](https://www.gmicloud.ai/)
2. **API key**: create a key in the [GMI Cloud console](https://console.gmicloud.ai/)

### Required Environment Variables

- `GMI_CLOUD_API_KEY`: your GMI Cloud API key, passed to the `api_key` constructor argument.

## Configuration

<ParamField path="api_key" type="str" required>
  GMI Cloud API key for authentication.
</ParamField>

<ParamField path="aiohttp_session" type="aiohttp.ClientSession" required>
  HTTP client session used for GMI Cloud API requests.
</ParamField>

<ParamField path="url" type="str" default="https://console.gmicloud.ai">
  GMI Cloud console API base URL.
</ParamField>

<ParamField path="audio_format" type="str" default="WAV">
  Output container requested from the API. PCM-bearing formats stream into Pipecat.
</ParamField>

<ParamField path="poll_interval_secs" type="float" default="2.0">
  Seconds between status polls for queued generations.
</ParamField>

<ParamField path="poll_attempts" type="int" default="15">
  Maximum status polls (about 30 seconds) before giving up.
</ParamField>

<ParamField
  path="settings"
  type="GmicloudHttpTTSService.Settings"
  default="None"
>
  Runtime-configurable synthesis settings. See [Settings](#settings) below.
</ParamField>

### Settings

Runtime-configurable settings passed via the `settings` constructor argument
using `GmicloudHttpTTSService.Settings(...)`.

| Setting         | Default            | Description                                                                                     |
| --------------- | ------------------ | ----------------------------------------------------------------------------------------------- |
| `model`         | `"inworld-tts-2"`  | Any GMI Cloud audio model id.                                                                   |
| `voice`         | per family         | Inworld: `Dennis` (282 voices); MiniMax: `English_expressive_narrator`; Chatterbox: your Resemble `voice_uuid` (required). |
| `language`      | `Language.EN`      | Language hint (voices define the spoken language).                                              |
| `speed`         | `1.0`              | Speaking-rate multiplier, mapped to each family's rate field.                                    |
| `temperature`   | model default      | Randomness (Inworld family only).                                                                |
| `timestamp_type`| unset              | Optional alignment request, e.g. `WORD` (Inworld family only).                                   |
| `extra_payload` | `{}`               | Provider-specific fields merged into the request unchanged.                                      |

<Note>
  GMI Cloud models do not share a single request shape, so the service maps each
  model family's fields (Inworld, MiniMax, Chatterbox) automatically. See the
  [source repository](https://github.com/Jayanng/pipecat-gmicloud) for the full
  model table and live verification results.
</Note>

## Usage

```python
import os
import aiohttp
from pipecat_gmicloud import GmicloudHttpTTSService

async with aiohttp.ClientSession() as session:
    tts = GmicloudHttpTTSService(
        api_key=os.environ["GMI_CLOUD_API_KEY"],
        aiohttp_session=session,
        settings=GmicloudHttpTTSService.Settings(
            model="inworld-tts-2",
            voice="Dennis",
        ),
    )
    # Drop into any Pipecat pipeline:
    # Pipeline([tts, transport.output()])
```
