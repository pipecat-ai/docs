## Overview

Plivo provides text-to-speech with [Koyal](https://www.plivo.com/docs/models/text-to-speech/overview), its TTS model, through two service implementations: `PlivoTTSService` streams over Plivo's Realtime API on one WebSocket, with one context per turn and word timestamps, and `PlivoHttpTTSService` sends one Batch API request per sentence. `PlivoTTSService` is recommended for interactive applications requiring low latency.

## Installation

```bash
uv add "pipecat-ai[plivo]"
```

## Prerequisites

### Plivo Account Setup

Before using Plivo TTS services, you need:

1. **Plivo Account**: Sign up at [Plivo](https://www.plivo.com/)
2. **Auth ID and Auth Token**: Get them from your Plivo console
3. **Voice Selection** (optional): Choose a voice ID for the Koyal model. If you don't, the service uses the default voice, Hailey (US English)

### Required Environment Variables

- `PLIVO_AUTH_ID`: Your Plivo auth ID
- `PLIVO_AUTH_TOKEN`: Your Plivo auth token

### Settings

Runtime-configurable settings passed via the `settings` constructor argument using `PlivoTTSService.Settings(...)` (or `PlivoHttpTTSService.Settings(...)`). These can be updated mid-conversation with `TTSUpdateSettingsFrame`. See [Service Settings](/pipecat/fundamentals/service-settings) for details.

| Parameter                     | Type              | Default | Description                                                                                                                                                                                               |
| ----------------------------- | ----------------- | ------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `model`                       | `str`             | `None`  | TTS model. When unset, uses `"koyal-v1"`. _(Inherited.)_                                                                                                                                                  |
| `voice`                       | `str`             | `"lC7qzMoRE7SSjaNCVeff"` | Voice ID. Defaults to Hailey, a US English voice. _(Inherited.)_                                                                                                                                                                                  |
| `language`                    | `Language \| str` | `None`  | Language of the text. For English, the region (`EN_IN`, `EN_US`, `EN_GB` or `EN_AU`) sets how numbers and dates are normalized. When unset, the model finds the language of each sentence. _(Inherited.)_ |
| `speed`                       | `float`           | `None`  | Speaking rate, from 0.7 to 1.2. Plivo's default is `1.0`.                                                                                                                                                 |
| `volume`                      | `float`           | `None`  | Volume of the speech, from 0.5 to 2.0. Plivo's default is `1.0`.                                                                                                                                          |
| `pronunciation_dictionary_id` | `str`             | `None`  | ID of a pronunciation dictionary whose rules set the pronunciation of a word in IPA, ARPAbet or as a respelling.                                                                                          |
| `seed`                        | `int`             | `None`  | Seed of the speech, from 0 to 2\*\*53 - 1. Defaults to the voice's default seed.                                                                                                                          |
| `continuation`                | `bool`            | `None`  | Whether the speech of a context continues from the previous context's. Realtime API only. Plivo's default is `True`.                                                                                      |
| `text_normalization`          | `bool`            | `None`  | Whether the model spells out numbers, dates and similar text before speech. Plivo's default is `True`.                                                                                                    |

With `PlivoTTSService`, a new model, voice or language during a turn applies to the rest of the turn, and any other setting applies from the next context. With `PlivoHttpTTSService`, an update applies from the next request.

## Usage

### Basic Setup

```python
import os

from pipecat.services.plivo.tts import PlivoTTSService

tts = PlivoTTSService(
    auth_id=os.environ["PLIVO_AUTH_ID"],
    auth_token=os.environ["PLIVO_AUTH_TOKEN"],
    settings=PlivoTTSService.Settings(
        voice="lC7qzMoRE7SSjaNCVeff",
    ),
)
```

### HTTP Service

```python
import aiohttp

from pipecat.services.plivo.tts import PlivoHttpTTSService

async with aiohttp.ClientSession() as session:
    tts = PlivoHttpTTSService(
        auth_id=os.environ["PLIVO_AUTH_ID"],
        auth_token=os.environ["PLIVO_AUTH_TOKEN"],
        aiohttp_session=session,
        settings=PlivoHttpTTSService.Settings(
            voice="lC7qzMoRE7SSjaNCVeff",
        ),
    )
```

## Notes

- **Word timestamps**: `PlivoTTSService` builds its text frames from the per-character timestamps the Realtime API returns, so word tracking follows the audio.
- **Pronunciations**: Phoneme spans between braces, such as `{ˈpliːvoʊ}`, take IPA or ARPAbet. Pipecat renders them for pronunciation rules. Alternatively, apply `text_transforms` find-and-replace rules before the text reaches Plivo.

## Event Handlers

`PlivoTTSService` supports the standard [service connection events](/api-reference/server/events/service-events):

| Event                 | Description                         |
| --------------------- | ----------------------------------- |
| `on_connected`        | Connected to Plivo WebSocket        |
| `on_disconnected`     | Disconnected from Plivo WebSocket   |
| `on_connection_error` | WebSocket connection error occurred |

```python
@tts.event_handler("on_connected")
async def on_connected(service):
    print("Connected to Plivo")
```
