## Overview

`HeyGenTTSService` streams text to HeyGen Voice over a WebSocket and plays the audio as it arrives, with word-level timestamps so an interruption commits only the words actually spoken. `HeyGenHttpTTSService` streams raw PCM audio from HeyGen's HTTP endpoint, one request per sentence, and also serves professional voice clones.

## Installation

```bash
uv add pipecat-ai
```

HeyGen TTS needs no extra dependencies. The `heygen` extra is only for the [HeyGen video avatar](/api-reference/server/services/video/heygen).

## Prerequisites

### HeyGen Account Setup

Before using HeyGen TTS, you need:

1. **HeyGen Account**: Sign up at [HeyGen](https://www.heygen.com/)
2. **API Key**: Generate an API key from your account
3. **Voice Selection**: Choose a public voice ID, or use an instant or professional clone from your workspace

### Required Environment Variables

- `HEYGEN_API_KEY`: Your HeyGen API key for authentication

## Configuration

### HeyGenTTSService

<ParamField path="api_key" type="str" required>
  HeyGen API key.
</ParamField>

<ParamField path="url" type="str" default="wss://api.heygen.com">
  HeyGen WebSocket base URL.
</ParamField>

<ParamField path="sample_rate" type="int | None" default="None">
  Output audio sample rate in Hz. When `None`, uses the pipeline's sample rate.
</ParamField>

<ParamField path="enable_ssml_parsing" type="bool | None" default="None">
  Whether `<break time="1s" />` tags become pauses. Without it, HeyGen closes
  the WebSocket when the text contains a break tag.
</ParamField>

<ParamField path="enable_logging" type="bool | None" default="None">
  Whether HeyGen stores a copy of the audio and text. When `None`, HeyGen stores
  them.
</ParamField>

<ParamField path="end_user_id" type="str | None" default="None">
  Your identifier for the end user, recorded with HeyGen's usage for
  attribution.
</ParamField>

<ParamField
  path="text_aggregation_mode"
  type="TextAggregationMode | None"
  default="None"
>
  How incoming text is aggregated before synthesis. `TextAggregationMode.TOKEN`
  streams LLM tokens as they arrive, and HeyGen generates at each sentence end.
</ParamField>

<ParamField path="settings" type="HeyGenTTSService.Settings" default="None">
  Runtime-configurable settings. See [Settings](#settings) below.
</ParamField>

### Settings

Runtime-configurable settings passed via the `settings` constructor argument using `HeyGenTTSService.Settings(...)`. These can be updated mid-conversation with `TTSUpdateSettingsFrame`; any change reconnects the WebSocket. See [Service Settings](/pipecat/fundamentals/service-settings) for details.

| Parameter                  | Type                      | Default                  | Description                                                                                                  |
| -------------------------- | ------------------------- | ------------------------ | ------------------------------------------------------------------------------------------------------------ |
| `model`                    | `str`                     | `"heygen-voice-1-turbo"` | HeyGen Voice model: `heygen-voice-1`, `heygen-voice-1-turbo`, or `heygen-voice-1-turbo-free`. _(Inherited.)_ |
| `voice`                    | `str`                     | Nadine's public voice ID | HeyGen voice ID: a public voice or an instant clone in your workspace. _(Inherited.)_                        |
| `language`                 | `Language \| str`         | `None`                   | Language of the text. When `None`, HeyGen detects it. _(Inherited.)_                                         |
| `apply_text_normalization` | `"auto" \| "on" \| "off"` | `None`                   | Text normalization mode. When `None`, HeyGen uses `"auto"`.                                                  |
| `expressiveness_boost`     | `float`                   | `None`                   | Voice expressiveness from 0.0 to 1.0. When `None`, HeyGen chooses it.                                        |

Passed via `HeyGenHttpTTSService.Settings(...)` and updatable with `TTSUpdateSettingsFrame`.

| Parameter  | Type              | Default                  | Description                                                                                                                       |
| ---------- | ----------------- | ------------------------ | --------------------------------------------------------------------------------------------------------------------------------- |
| `model`    | `str`             | `"heygen-voice-1-turbo"` | HeyGen Voice model: `heygen-voice-1`, `heygen-voice-1-turbo`, or `heygen-voice-1-turbo-free`. _(Inherited.)_                      |

## Usage

### Basic Setup

```python
import os

from pipecat.services.heygen.tts import HeyGenTTSService

tts = HeyGenTTSService(
    api_key=os.getenv("HEYGEN_API_KEY"),
    settings=HeyGenTTSService.Settings(voice="your-voice-id"),
)
```

### Professional Voice Clones

Only `HeyGenHttpTTSService` serves professional voice clones, and they need the `heygen-voice-1` model:

```python
import os

import aiohttp

from pipecat.services.heygen.tts import HeyGenHttpTTSService

async with aiohttp.ClientSession() as session:
    tts = HeyGenHttpTTSService(
        api_key=os.getenv("HEYGEN_API_KEY"),
        aiohttp_session=session,
        settings=HeyGenHttpTTSService.Settings(
            model="heygen-voice-1",
            voice="your-professional-clone-id",
        ),
    )
```

## Notes

- **Chinese and Japanese**: Set `language` on `HeyGenTTSService` to get per-character word timing. Without it, the service has no spaces to split words on, and the turn's text frames arrive only when its audio ends.
- **Turbo Free**: `heygen-voice-1-turbo-free` runs on shared capacity with no availability guarantee. When capacity is full, HeyGen refuses the turn and the service pushes an `ErrorFrame`. To keep the bot speaking, put a paid model behind it in a [`ServiceSwitcher`](/api-reference/server/composite-services/service-switcher) with `ServiceSwitcherStrategyFailover`.

## Event Handlers

`HeyGenTTSService` supports the standard [service connection events](/api-reference/server/events/service-events):

| Event                 | Description                         |
| --------------------- | ----------------------------------- |
| `on_connected`        | Connected to HeyGen WebSocket       |
| `on_disconnected`     | Disconnected from HeyGen WebSocket  |
| `on_connection_error` | WebSocket connection error occurred |

```python
@tts.event_handler("on_connected")
async def on_connected(service):
    print("Connected to HeyGen")
```
