## Overview

HeyGen provides two text-to-speech services for [HeyGen Voice](https://developers.heygen.com/docs/models/heygen-voice):

- **HeyGenTTSService**: Streams text over a WebSocket as the LLM produces it, and receives audio with word-level timestamps, so an interruption commits only the words actually spoken to the conversation context.
- **HeyGenHttpTTSService**: Sends each sentence in one HTTP request and streams the audio back.

## Installation

```bash
uv add pipecat-ai
```

HeyGen TTS needs no extra dependencies. The `heygen` extra is only for the [HeyGen video avatar](/api-reference/server/services/video/heygen).

## Prerequisites

1. **HeyGen Account**: Sign up at [HeyGen](https://www.heygen.com/).
2. **API Key**: Create an API key in your HeyGen account settings.
3. **Voice**: Use a public voice, or an instant or professional clone from your workspace. [Browse public voices](https://developers.heygen.com/docs/models/heygen-voice#hear-the-public-voices) in HeyGen's playground.

### Required Environment Variables

```bash
export HEYGEN_API_KEY=your_api_key
```

## Configuration

```python
from pipecat.services.heygen.tts import HeyGenHttpTTSService, HeyGenTTSService
```

### HeyGenTTSService

<ParamField path="api_key" type="str" required>
  HeyGen API key.
</ParamField>

<ParamField path="url" type="str" default="wss://api.heygen.com">
  HeyGen WebSocket base URL.
</ParamField>

<ParamField path="sample_rate" type="int | None" default="None">
  Output audio sample rate in Hz. `None` uses the pipeline's sample rate.
</ParamField>

<ParamField path="auto_mode" type="bool | None" default="None">
  Whether HeyGen starts generating at each sentence end instead of waiting for
  more text. `None` enables it unless `text_aggregation_mode` is
  `TextAggregationMode.TOKEN`, where HeyGen gathers enough text for natural
  speech on its own schedule.
</ParamField>

<ParamField
  path="text_aggregation_mode"
  type="TextAggregationMode | None"
  default="None"
>
  How to aggregate incoming text before synthesis. `None` aggregates sentences.
</ParamField>

<ParamField path="pause_frame_processing" type="bool" default="True">
  Whether to hold incoming frames after a turn until its audio has played. With
  `False`, turns synthesize concurrently on one WebSocket, and HeyGen closes the
  WebSocket when more than 5 are running.
</ParamField>

<ParamField path="settings" type="HeyGenTTSService.Settings" default="None">
  Runtime-configurable settings. See [WebSocket Settings](#websocket-settings).
</ParamField>

### WebSocket Settings

Runtime-configurable settings passed via the `settings` constructor argument using `HeyGenTTSService.Settings(...)`. Update them mid-conversation with `TTSUpdateSettingsFrame`; any change reconnects the WebSocket. See [Service Settings](/pipecat/fundamentals/service-settings) for details.

| Parameter  | Type              | Default                              | Description                                                                                                            |
| ---------- | ----------------- | ------------------------------------ | ---------------------------------------------------------------------------------------------------------------------- |
| `model`    | `str`             | `"heygen-voice-1-turbo"`             | HeyGen Voice model: `heygen-voice-1` or `heygen-voice-1-turbo`. _(Inherited from base settings.)_                      |
| `voice`    | `str`             | `"83548de556df48ba8c09c42a57c51d85"` | Voice ID: a public voice or an instant clone. The default is Nadine, a public voice. _(Inherited from base settings.)_ |
| `language` | `Language \| str` | `None`                               | Language of the text. `None` lets HeyGen detect it. _(Inherited from base settings.)_                                  |

### HeyGenHttpTTSService

<ParamField path="api_key" type="str" required>
  HeyGen API key.
</ParamField>

<ParamField path="aiohttp_session" type="aiohttp.ClientSession" required>
  aiohttp session for HTTP requests.
</ParamField>

<ParamField path="base_url" type="str" default="https://api.heygen.com">
  HeyGen API base URL.
</ParamField>

<ParamField path="sample_rate" type="int | None" default="None">
  Output audio sample rate in Hz. `None` uses the pipeline's sample rate. At a
  rate HeyGen does not synthesize, the service requests 24000 Hz and resamples.
</ParamField>

<ParamField path="settings" type="HeyGenHttpTTSService.Settings" default="None">
  Runtime-configurable settings. See [HTTP Settings](#http-settings).
</ParamField>

### HTTP Settings

Runtime-configurable settings for `HeyGenHttpTTSService` using `HeyGenHttpTTSService.Settings(...)`.

| Parameter  | Type              | Default                              | Description                                                                                                                             |
| ---------- | ----------------- | ------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------- |
| `model`    | `str`             | `"heygen-voice-1-turbo"`             | HeyGen Voice model: `heygen-voice-1`, `heygen-voice-1-turbo` or `heygen-voice-1-turbo-free`. _(Inherited from base settings.)_          |
| `voice`    | `str`             | `"83548de556df48ba8c09c42a57c51d85"` | Voice ID: a public voice, or an instant or professional clone. The default is Nadine, a public voice. _(Inherited from base settings.)_ |
| `language` | `Language \| str` | `None`                               | Language of the text. `None` lets HeyGen detect it. _(Inherited from base settings.)_                                                   |

## Usage

### Stream Speech Over a WebSocket

Pass the voice you want; HeyGen's [model and voice docs](https://developers.heygen.com/docs/models/heygen-voice) list what each model serves:

```python
import os

from pipecat.services.heygen.tts import HeyGenTTSService

tts = HeyGenTTSService(
    api_key=os.getenv("HEYGEN_API_KEY"),
    settings=HeyGenTTSService.Settings(
        voice=os.getenv("HEYGEN_VOICE_ID"),
    ),
)
```

### Use a Professional Voice Clone

Professional clones are served over HTTP, on `heygen-voice-1`:

```python
import aiohttp

from pipecat.services.heygen.tts import HeyGenHttpTTSService

async with aiohttp.ClientSession() as session:
    tts = HeyGenHttpTTSService(
        api_key=os.getenv("HEYGEN_API_KEY"),
        aiohttp_session=session,
        settings=HeyGenHttpTTSService.Settings(
            model="heygen-voice-1",
            voice=os.getenv("HEYGEN_VOICE_ID"),
        ),
    )
```

### Switch Language Mid-Conversation

Push a `TTSUpdateSettingsFrame` with the new language:

```python
from pipecat.frames.frames import TTSUpdateSettingsFrame
from pipecat.transcriptions.language import Language

await worker.queue_frame(
    TTSUpdateSettingsFrame(delta=HeyGenTTSService.Settings(language=Language.ES))
)
```

## Notes

- **Service choice**: Use `HeyGenTTSService` for the lowest latency and word timestamps. Use `HeyGenHttpTTSService` for professional voice clones and `heygen-voice-1-turbo-free`, which the WebSocket does not serve.
- **Regional languages**: HeyGen Voice has no regional accents, so a regional `Language` such as `Language.EN_US` is sent as its base language, `en`. HeyGen's docs list the [supported languages](https://developers.heygen.com/docs/voices/heygen-voice-speech#supported-languages).
- **Rate limits**: HeyGen limits speech requests per workspace member. `HeyGenHttpTTSService` makes one request per sentence, so a busy bot can reach the limit; a rejected request is pushed as an `ErrorFrame`.
