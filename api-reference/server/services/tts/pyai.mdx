## Overview

`PyAITTSService` provides streamed PCM speech synthesis through PyAI Speak in a Pipecat pipeline.

## Installation

```bash
uv add pipecat-pyai==0.1.4
```

Python 3.11 or newer is required. The package declares Pipecat `>=1.3.0,<2.0`.
A two-turn audio flow was exercised with Pipecat 1.8.1; this is not qualification
of every version in that range. Version 0.1.4's STT startup-settings correction
was checked separately from that earlier audio run.

## Prerequisites

Create a PyAI account and a server-side key with the `speak:synthesize` scope.
Before running audio, verify the selected project, billing environment, and
limits with `GET https://api.pyai.com/v1/me`. Usage is charged or limited according
to that key; Pipecat hosting, transport, and LLM costs are separate.

### Required Environment Variables

- `PYAI_API_KEY`: the server-side PyAI key. Keep it out of browser code and source control.

## Configuration

```python
from pipecat_pyai import PyAITTSService
```

### PyAITTSService

<ParamField path="voice" type="str" required>
  Required streaming-capable voice ID from `GET https://api.pyai.com/v1/voices`.
</ParamField>

<ParamField path="api_key" type="str | None">
  Default: `None`. Server-side PyAI key. When omitted, reads `PYAI_API_KEY`.
  Raises `ValueError` if neither is supplied.
</ParamField>

<ParamField path="base_url" type="str" default="https://api.pyai.com">
  PyAI API base URL.
</ParamField>

<ParamField path="model" type="str" default="pyai-speak">
  PyAI model identifier.
</ParamField>

<ParamField path="sample_rate" type="int | None">
  Default: `None`. Audio sample rate in Hz. When omitted, uses the pipeline
  audio rate.
</ParamField>

<ParamField path="aiohttp_session" type="aiohttp.ClientSession | None">
  Default: `None`. Optional HTTP session owned by the caller. When omitted, the
  service creates and closes its own session.
</ParamField>

Additional keyword arguments are forwarded to Pipecat's base service.

### Settings

Configure provider options in the constructor. The adapter initializes Pipecat
settings metadata, but does not implement runtime provider-setting updates.
Create a new service to change model or voice; do not pass a second `settings=` argument.

## Usage

The following function builds the output part of a pipeline from existing components.
See the [complete WebRTC demo](https://github.com/atomsai/pyai-speech-integrations/blob/main/demos/pipecat_bot.py)
for transport, VAD, LLM, worker, and disconnect handling.

```python
from pipecat.pipeline.pipeline import Pipeline
from pipecat_pyai import PyAITTSService


def speech_output(llm, transport, assistant_aggregator):
    tts = PyAITTSService(voice="stock_emma_en_gb")
    return Pipeline([llm, tts, transport.output(), assistant_aggregator])
```

## Frames

Generated PCM is delivered in `TTSAudioRawFrame` objects. The Pipecat base TTS service handles text and utterance framing.
