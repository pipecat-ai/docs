## Overview

`GoogleImageGenService` provides high-quality image generation capabilities using Google's Gemini image models. It supports generating multiple images from text prompts with various customization options and advanced prompt understanding for photorealistic and artistic image creation.

## Installation

To use Google image generation services, install the required dependencies:

```bash
uv add "pipecat-ai[google]"
```

## Prerequisites

### Google Cloud Setup

Before using Google image generation services, you need:

1. **Google Cloud Account**: Set up at [Google Cloud Console](https://console.cloud.google.com/)
2. **API Key**: Generate a Google API key with Gemini API access
3. **Project Configuration**: Enable Gemini API for your project
4. **Model Access**: Ensure access to Gemini image models

### Required Environment Variables

- `GOOGLE_API_KEY`: Your Google API key for authentication

  HTTP options for the Google AI client.
</ParamField>

<ParamField
  path="settings"
  type="GoogleImageGenService.Settings"
  default="None"
>
  Runtime-configurable generation settings. See [Settings](#settings) below.
</ParamField>

### Settings

Runtime-configurable settings passed via the `settings` constructor argument using `GoogleImageGenService.Settings(...)`. See [Service Settings](/pipecat/fundamentals/service-settings) for details.

| Parameter          | Type          | Default     | Description                                                                                                                                     |
| ------------------ | ------------- | ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| `model`            | `str`         | `NOT_GIVEN` | Gemini image model identifier. _(Inherited from base settings.)_                                                                                |
| `number_of_images` | `int`         | `NOT_GIVEN` | Number of images to generate per prompt (1-8). Each image is a separate request.                                                                |
| `aspect_ratio`     | `str \| None` | `NOT_GIVEN` | Aspect ratio of generated images, such as `"1:1"` or `"16:9"`. `None` leaves the model's own default in place.                                  |
| `negative_prompt`  | `str \| None` | `NOT_GIVEN` | _Deprecated in 1.13.0. No replacement._ Gemini image models do not accept a negative prompt, so the value is ignored. Will be removed in 2.0.0. |

<Note>
  `NOT_GIVEN` values are omitted from the request, letting the service use its
  own defaults (`"gemini-3.1-flash-image"` for model, `1` for number_of_images,
  `"1:1"` for aspect_ratio). Only parameters that are explicitly set are
  included.
</Note>

## Usage

### Basic Setup

```python
from pipecat.services.google.image import GoogleImageGenService

image_gen = GoogleImageGenService(
    api_key=os.getenv("GOOGLE_API_KEY"),
)
```

### With Settings

```python
image_gen = GoogleImageGenService(
    api_key=os.getenv("GOOGLE_API_KEY"),
    settings=GoogleImageGenService.Settings(
        model="gemini-3.1-flash-image",
        number_of_images=2,
        aspect_ratio="16:9",
    ),
)
```

<Tip>
  The `InputParams` / `params=` pattern is deprecated as of v0.0.105. Use
  `Settings` / `settings=` instead. See the [Service Settings
  guide](/pipecat/fundamentals/service-settings) for migration details.
</Tip>

## Notes

- **RGB output**: Generated images are converted to RGB format for compatibility with output transports that render RGB video by default.
- **Sequential generation**: When `number_of_images` is greater than 1, each image is generated in a separate request, processed one after another.
- **No HTTP session needed**: Google returns image data directly in the API response, so no separate HTTP session is required for downloading.
- **Metrics support**: Google image generation supports TTFB metrics tracking.
