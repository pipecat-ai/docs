## Overview

`OjinVideoService` turns the TTS audio in your pipeline into a lip-synced video
avatar using [Ojin](https://ojin.ai). It is maintained by Ojin, the company that
provides the service. By default it pushes synchronized audio and video frames to
your transport. With `OjinVideoSettings.webrtc` set, Ojin joins your LiveKit or
Daily room as the `ojin-avatar` participant and publishes the avatar there, so the
service pushes no media frames.

## Installation

This is a community-maintained package distributed separately from `pipecat-ai`:

```bash
uv add pipecat-ojin
```

## Prerequisites

1. **Ojin account**: get an API key and a Face model config ID from [ojin.ai](https://ojin.ai).
2. API keys for the STT, LLM and TTS services in your pipeline.
3. For direct WebRTC: a LiveKit or Daily room that Ojin can reach, and a token for the avatar.

### Required Environment Variables

- `OJIN_API_KEY`: your Ojin API key
- `OJIN_CONFIG_ID`: the Face model (avatar) configuration to drive

## Configuration

<ParamField path="settings" type="OjinVideoSettings" required>
  Connection identity and options: `api_key`, `config_id`, `ws_url`,
  `buffer_preinit_tts_audio`, `stv_config`, and `webrtc` (optional direct WebRTC
  settings).
</ParamField>

<ParamField
  path="session_trace"
  type="ojin.stv.OjinSessionTrace"
  default="None"
>
  Optional per-call trace, dumped when the session closes.
</ParamField>

<Note>
  See the [source repository](https://github.com/ojinai/pipecat-ojin) for the
  authoritative parameter list. Set your transport's `video_out_width` and
  `video_out_height` to your Face model's frame size when using the WebSocket
  path.
</Note>

## Usage

```python
import os

from pipecat.pipeline.pipeline import Pipeline
from pipecat_ojin import OjinVideoService, OjinVideoSettings

avatar = OjinVideoService(
    OjinVideoSettings(
        api_key=os.environ["OJIN_API_KEY"],
        config_id=os.environ["OJIN_CONFIG_ID"],
    )
)

pipeline = Pipeline([
    transport.input(),
    stt,
    context_aggregator.user(),
    llm,
    tts,
    avatar,  # Ojin video avatar, after TTS
    transport.output(),
    context_aggregator.assistant(),
])
```

See the [foundational example](https://github.com/ojinai/pipecat-ojin/blob/main/examples/foundational/ojin_livekit_avatar.py)
for a complete LiveKit pipeline.

## Compatibility

Tested with Pipecat v1.3.0 and v1.16.0 (Python 3.11+).
Check the [source repository](https://github.com/ojinai/pipecat-ojin) for the latest
tested version and changelog.
