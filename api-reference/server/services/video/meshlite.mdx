## Overview

[MeshLite](https://meshlite.io) draws a lip-synced avatar face in the visitor's browser,
from the audio track the page already receives from your bot. The bot keeps its own
STT, LLM, TTS and transport: the pipeline carries no video frames, and the bot's audio is
not changed or delayed.

`MeshLiteAvatarProcessor` is a pass-through processor. It answers the page's
`meshlite-session` RTVI request with a MeshLite session created with your secret key,
and reads the words the bot speaks: when a reply is clearly in another language
(English, French or Mandarin Chinese), it sends a `meshlite-language` server message and
the page switches to the lip model of that language. The lips follow the bot's voice,
not the visitor's speech-to-text. In the page, the MeshLite web SDK takes the bot's
audio track and Pipecat's RTVI events with `avatar.attachPipecat(client)`; on
`botInterrupted` the face stops at once.

Place it after the TTS service. Tested with the SmallWebRTC transport; the processor
only uses RTVI messages, so other browser transports should work too.

<Warning>
  The face is rendered by the MeshLite web SDK in your page. A client without
  the SDK, such as Pipecat's prebuilt UI, plays the bot's voice but shows no
  face. See [Browser](#browser).
</Warning>

## Installation

This is a community-maintained package distributed separately from `pipecat-ai`:

```bash
uv add pipecat-meshlite
```

The page loads the MeshLite web SDK (1.11.60 or newer) from
`https://console.meshlite.io/sdk/1.11.60/meshlite.js`.

## Prerequisites

### MeshLite Account Setup

In the MeshLite Console (Projects, then **For developers**):

1. **Allowed sites**: add the address of your page
2. **Keys**: create a publishable key and a secret key of the same environment (test or live)
3. **Code**: copy your avatar ID

RTVI must be enabled (Pipecat's default for `PipelineWorker`).

### Required Environment Variables

- `MESHLITE_PUBLISHABLE_KEY`: your publishable key (also given to the page)
- `MESHLITE_SECRET_KEY`: your secret key (server only)
- `MESHLITE_ORIGIN`: the address of your page, for example `https://www.example.com`
- `MESHLITE_AVATAR` (optional): the avatar ID

## Configuration

Constructor parameters for `MeshLiteAvatarProcessor` (keyword arguments):

<ParamField path="client" type="MeshLiteClient" default="None">
  Creates the sessions. Defaults to a `MeshLiteClient` configured from the
  `MESHLITE_*` environment variables.
</ParamField>

<ParamField path="avatar" type="str" default="None">
  Avatar ID. Defaults to the client's avatar.
</ParamField>

<ParamField path="language" type="Language | str" default="None">
  The language the bot speaks at the start. It picks the lip model of each new
  session: English, French or Mandarin Chinese; any other language uses MeshLite's
  multilingual lip model (`auto`).
</ParamField>

<ParamField path="max_sessions" type="int" default="3">
  Most session requests sent to MeshLite for one connection, refusals included
  (1 to 10). Each session counts as a MeshLite conversation.
</ParamField>

<ParamField path="follow_language" type="bool" default="True">
  Send `meshlite-language` to the page when the language the bot speaks changes.
  A bot that switches language on purpose can also call
  `await avatar.set_language("fr")`.
</ParamField>

## Usage

### Pipeline

```python
from pipecat.pipeline.pipeline import Pipeline
from pipecat.transcriptions.language import Language
from pipecat_meshlite import MeshLiteAvatarProcessor

avatar = MeshLiteAvatarProcessor(language=Language.EN)

pipeline = Pipeline([
    transport.input(),
    stt,
    user_aggregator,
    llm,
    tts,
    avatar,  # pass-through: the bot's audio is not changed
    transport.output(),
    assistant_aggregator,
])
```

### Browser

Mount the face with `audio: "track"`, let it ask the bot for its session, and attach the
`PipecatClient` before connecting:

```javascript
const client = new PipecatClient({
  transport,
  enableMic: true,
  callbacks: {
    onBotReady: () => botReady(),
    onServerMessage: (m) => {
      if (m?.type === "meshlite-language") avatar.setLanguage(m.language);
    },
  },
});
const avatar = MeshLite.mount({
  container: "#avatar",
  avatar: avatarId,
  publishableKey,
  audio: "track",
  sessionToken: async () => {
    await ready; // resolved by onBotReady
    const reply = await client.sendClientRequest("meshlite-session", {});
    return (reply?.d ?? reply).sessionToken;
  },
});
avatar.attachPipecat(client);
await client.connect(connectParams);
```

See the [one-file example](https://github.com/meshlite-avatar/pipecat-meshlite/blob/main/examples/bot.py)
(bot and page) and the [MeshLite Pipecat guide](https://meshlite.io/docs#pipecat) for
events, fallback and latency.

## Compatibility

Tested with Pipecat v1.16.0 (Python 3.12) and v1.15.0 (Python 3.11) on SmallWebRTC, with `@pipecat-ai/client-js`
1.16.0 and the MeshLite web SDK 1.11.60. Check the
[source repository](https://github.com/meshlite-avatar/pipecat-meshlite) for the latest
compatibility notes.
