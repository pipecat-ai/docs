## Overview

`SimliVideoService` integrates with Simli to create real-time AI avatar video experiences using WebRTC streaming. The service processes audio input to generate synchronized avatar video and audio output, handling real-time streaming, audio resampling, and conversation interruptions for engaging conversational AI applications.

## Installation

To use Simli services, install the required dependency:

```bash
uv add "pipecat-ai[simli]"
```

## Prerequisites

### Simli Account Setup

Before using Simli video services, you need:

1. **Simli Account**: Sign up at [Simli Platform](https://www.simli.com/)
2. **API Key**: Generate an API key from your account dashboard
3. **Face Selection**: Choose or create avatar faces for video generation
4. **WebRTC Setup**: Configure real-time streaming capabilities

### Required Environment Variables

- `SIMLI_API_KEY`: Your Simli API key for authentication
- `SIMLI_FACE_ID`: ID of your avatar face

## Configuration

<ParamField path="api_key" type="str" required>
  Simli API key for authentication.
</ParamField>

<ParamField path="face_id" type="str" required>
  Simli Face ID. For Trinity avatars, specify `"faceId/emotionId"` to use a
  different emotion than the default.
</ParamField>

<ParamField path="simli_url" type="str" default="https://api.simli.ai">
  URL of the Simli servers. Can be changed for custom deployments by enterprise
  users.
</ParamField>

<ParamField path="is_trinity_avatar" type="bool" default="None" deprecated>
  _Deprecated since 1.16.0, removed in 2.0.0._ No replacement; it has no effect.
</ParamField>

<ParamField path="max_session_length" type="int" default="None">
  Absolute maximum session duration in seconds. Avatar disconnects after this
  time even if speaking.
</ParamField>

<ParamField path="max_idle_time" type="int" default="None">
  Maximum duration in seconds the avatar can be idle (not speaking) before
  disconnecting.
</ParamField>

<ParamField path="enable_logging" type="bool" default="None">
  Accepted but has no effect: the value is not passed to Simli.
</ParamField>

<ParamField path="framing" type="SimliFraming" default="None">
  Framing for Trinity-2 faces; other faces keep their own frame size. `None`
  keeps Simli's defaults (768x768, avatar at the bottom center). Set the output
  transport's `video_out_width` and `video_out_height` to match
  `streaming_width` and `streaming_height`. See [Framing](#framing) below.
</ParamField>

<ParamField path="settings" type="SimliVideoSettings" default="None">
  Service settings. Use `SimliVideoService.Settings(...)` for configuration.
</ParamField>

<ParamField path="params" type="InputParams" default="None">
  <Warning>
    **Deprecated since 0.0.106**: Use the direct constructor parameters
    (`max_session_length`, `max_idle_time`, `enable_logging`) or
    `settings=SimliVideoService.Settings(...)` instead.
  </Warning>
  Additional input parameters for session configuration. See
  [InputParams](#inputparams) below.
</ParamField>

### Framing

`SimliVideoService.Framing(...)` fields. A field left as `None` keeps Simli's
default.

| Parameter           | Type                      | Default | Description                                                                                                                           |
| ------------------- | ------------------------- | ------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| `streaming_width`   | `int`                     | `None`  | Video width in pixels, at least 512. With `streaming_height` it must make a 1:1, 16:9, or 9:16 frame, such as 1366x768. Default 768. |
| `streaming_height`  | `int`                     | `None`  | Video height in pixels, at least 512. Default 768.                                                                                    |
| `avatar_position_x` | `float`                   | `None`  | Where the avatar sits across the video, from 0 (left) to 1 (right). Default 0.5.                                                     |
| `avatar_position_y` | `float`                   | `None`  | Where the avatar sits down the video, from 0 (top) to 1 (bottom). Default 1.                                                         |
| `camera`            | `SimliCamera`              | `None`  | Camera the session starts with. `None` keeps the avatar's own framing.                                                                |
| `background_id`     | `str`                     | `None`  | ID of a background uploaded to your Simli account, shown behind the avatar.                                                           |
| `foreground_id`     | `str`                     | `None`  | ID of a foreground uploaded to your Simli account, laid over the avatar.                                                              |

`SimliVideoService.Camera(...)` fields are offsets on top of the avatar's own
framing; an unset field stays neutral (0, or 1 for `zoom`).

| Parameter     | Type    | Description                                                         |
| ------------- | ------- | ------------------------------------------------------------------- |
| `pos_x_off`   | `float` | Moves the avatar right, in half canvas widths (-10 to 10).          |
| `pos_y_off`   | `float` | Moves the avatar down, in half canvas heights (-10 to 10).          |
| `pos_z_off`   | `float` | Metres the camera backs away from the avatar; negative moves in (-5 to 5). |
| `rot_x_off`   | `float` | Degrees the camera tilts up (-180 to 180).                          |
| `rot_y_off`   | `float` | Degrees the camera pans right (-180 to 180).                        |
| `rot_z_off`   | `float` | Degrees the camera rolls clockwise (-180 to 180).                   |
| `zoom`        | `float` | Multiplies the avatar's zoom; 1 is no change (above 0, up to 4).    |
| `orbit_x_off` | `float` | Degrees the camera orbits up over the avatar's head (-80 to 80).    |
| `orbit_y_off` | `float` | Degrees the camera orbits round to its right (-180 to 180).         |

## Usage

### Basic Setup

```python
import os

from pipecat.services.simli.video import SimliVideoService

simli = SimliVideoService(
    api_key=os.getenv("SIMLI_API_KEY"),
    face_id=os.getenv("SIMLI_FACE_ID"),
)
```

### With Session Configuration

```python
simli = SimliVideoService(
    api_key=os.getenv("SIMLI_API_KEY"),
    face_id=os.getenv("SIMLI_FACE_ID"),
    max_session_length=600,
    max_idle_time=120,
)
```

### With Trinity-2 Framing

```python
simli = SimliVideoService(
    api_key=os.getenv("SIMLI_API_KEY"),
    face_id=os.getenv("SIMLI_FACE_ID"),
    framing=SimliVideoService.Framing(
        streaming_width=1366,
        streaming_height=768,
        avatar_position_x=0.4,
    ),
)
```

### Using Settings (Alternative)

```python
simli = SimliVideoService(
    api_key=os.getenv("SIMLI_API_KEY"),
    face_id=os.getenv("SIMLI_FACE_ID"),
    settings=SimliVideoService.Settings(),
)
```

## Notes

- **Service architecture**: As of version 0.0.106, `SimliVideoService` extends `AIService` and supports `SimliVideoService.Settings(...)` for configuration, aligning it with other video services like HeyGen and Tavus.
- **Audio resampling**: The service resamples audio to 16kHz internally for the Simli API and resamples received audio back to the pipeline's sample rate.
- **Audio sources**: The avatar speaks `TTSAudioRawFrame` from a TTS service or `SpeechOutputAudioRawFrame` from speech-to-speech services that stream their voice, such as `OpenAILiveLLMService`. Audio goes to Simli as it arrives, and the avatar's voice is pushed as the same frame type.
- **Interruptions**: An `InterruptionFrame` clears Simli's buffer. A user speaking without interrupting the bot does not.
- **Deprecated parameters**:
  - `SimliVideoService.InputParams` is deprecated since 0.0.106. Use direct constructor parameters (`max_session_length`, `max_idle_time`, `enable_logging`) instead.
  - The `simli_config` and `use_turn_server` parameters have been removed. Use `api_key` and `face_id` directly as constructor parameters.
