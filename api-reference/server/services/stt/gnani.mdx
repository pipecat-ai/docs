## Overview

`GnaniHttpSTTService` and `GnaniSTTService` transcribe speech using
[Gnani](https://gnani.ai/), a production speech AI platform for 10+
Indian languages with real-time streaming and multilingual transcription.

Use `GnaniHttpSTTService` for REST-based file transcription of VAD-segmented
utterances, or `GnaniSTTService` for low-latency WebSocket streaming with
built-in VAD events. The WebSocket service emits `TranscriptionFrame` (final)
and `InterimTranscriptionFrame` when the API sets `is_final: false`.

## Installation

Install the community package directly:

```bash
uv add pipecat-gnani
```

This also installs the [`gnani-vachana`](https://pypi.org/project/gnani-vachana/)
(>= 0.9.0) core SDK. The Python import package name remains `gnani`.

## Prerequisites

### Gnani Account Setup

Before using the Gnani STT services, you need:

1. **Gnani API key**: Get one from [Gnani APIs](https://app.gnani.ai/voice).
2. **Set credentials**: Export `GNANI_API_KEY` as an environment variable.

### Required Environment Variables

- `GNANI_API_KEY`: Your Gnani API key for authentication

## Configuration

### `GnaniHttpSTTService` (REST)

<ParamField path="api_key" type="str" required>
  Gnani API key for authentication.
</ParamField>

<ParamField path="aiohttp_session" type="aiohttp.ClientSession" required>
  Shared aiohttp session for HTTP requests.
</ParamField>

<ParamField path="settings" type="GnaniHttpSTTService.Settings" default="None">
  Runtime-updatable STT settings. See [Settings](#settings) below.
</ParamField>

<Note>
  `GnaniHttpSTTService` extends `SegmentedSTTService` and requires VAD in the
  pipeline so that speech segments are buffered and sent as whole utterances.
  Each request is limited to 30 seconds of audio.
</Note>

### `GnaniSTTService` (WebSocket)

<ParamField path="api_key" type="str" required>
  Gnani API key for authentication.
</ParamField>

<ParamField path="sample_rate" type="int" default="None">
  Audio sample rate in Hz. One of `8000`, `16000`, `44100`, or `48000`. When
  omitted, the rate is negotiated from the pipeline configuration.
</ParamField>

<ParamField path="keepalive_timeout" type="float" default="None">
  Seconds of silence before sending keepalive audio. `None` disables keepalive.
</ParamField>

<ParamField path="keepalive_interval" type="float" default="5.0">
  Seconds between keepalive checks when keepalive is enabled.
</ParamField>

<ParamField path="settings" type="GnaniSTTService.Settings" default="None">
  Runtime-updatable STT settings. See [Settings](#settings) below.
</ParamField>

### Settings

Runtime-configurable settings passed via the `settings` constructor argument.

**`GnaniHttpSTTService.Settings`**

| Parameter             | Type                    | Default          | Description                                                                                                                                          |
| --------------------- | ----------------------- | ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `model`               | `str`                   | `None`           | `prisma-v2.5` or `prisma-v3.0`. When `None`, the Gnani default model (`prisma-v2.5`) is used.                                                        |
| `language`            | `Language \| str`       | `Language.EN_IN` | Recognition language (BCP-47, e.g. `Language.HI_IN`), or `"indic-auto"` to detect the language per utterance. `"indic-auto"` requires `prisma-v3.0`. |
| `language_candidates` | `list[Language \| str]` | `None`           | 2 to 4 likely languages. Requires `language="indic-auto"`. A hint, not a restriction.                                                                |
| `format`              | `str`                   | `None`           | `verbatim` for raw output or `transcribe` for ITN-normalized output. `codemix` and `transliterate` require `prisma-v3.0`.                            |
| `itn_native_numerals` | `bool`                  | `None`           | When `format="transcribe"`, render digits in native script.                                                                                          |
| `keywords`            | `list[str]`             | `None`           | Up to 200 words or phrases to favor. Requires `prisma-v3.0`.                                                                                         |
| `topic`               | `str`                   | `None`           | What the conversation is about, up to 1,600 characters. Requires `prisma-v3.0`.                                                                      |
| `previous_text`       | `str`                   | `None`           | Transcript that precedes the audio; the last 600 characters are used. Requires `prisma-v3.0`.                                                        |
| `speaker_names`       | `list[str]`             | `None`           | 1 to 4 speaker names. Requires `prisma-v3.0`.                                                                                                        |

**`GnaniSTTService.Settings`**

| Parameter             | Type                    | Default          | Description                                                                                                                                          |
| --------------------- | ----------------------- | ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `model`               | `str`                   | `None`           | `prisma-v2.5` or `prisma-v3.0`. When `None`, the Gnani default model (`prisma-v2.5`) is used.                                                        |
| `language`            | `Language \| str`       | `Language.EN_IN` | Recognition language (BCP-47, e.g. `Language.HI_IN`), or `"indic-auto"` to detect the language per utterance. `"indic-auto"` requires `prisma-v3.0`. |
| `language_candidates` | `list[Language \| str]` | `None`           | 2 to 4 likely languages. Requires `language="indic-auto"`. A hint, not a restriction.                                                                |
| `sample_rate`         | `int`                   | `None`           | Audio sample rate (`8000`, `16000`, `44100`, or `48000`).                                                                                            |
| `format`              | `str`                   | `None`           | `verbatim` for raw output or `transcribe` for ITN-normalized output. `codemix` and `transliterate` require `prisma-v3.0`.                            |
| `itn_native_numerals` | `bool`                  | `None`           | When `format="transcribe"`, render digits in native script.                                                                                          |
| `keywords`            | `list[str]`             | `None`           | Up to 200 words or phrases to favor. Requires `prisma-v3.0`.                                                                                         |

Settings that conflict with the chosen model or exceed a limit raise
`ValueError` when the service is created or updated. The WebSocket service takes
`keywords` as its only context hint; `topic`, `previous_text`, and
`speaker_names` are available on `GnaniHttpSTTService` only.

<Note>
  Changing `model`, `language`, `language_candidates`, `format`,
  `itn_native_numerals`, `keywords`, or `sample_rate` mid-session on the
  WebSocket service reconnects to re-run the init handshake. For the supported
  languages, see the [Gnani STT
  documentation](https://docs.gnani.ai/api/STT/speech-to-text#supported-languages).
</Note>

### Streaming PCM specification

WebSocket STT sends **raw PCM binary frames** — no WAV or MP3 container
mid-stream. Each frame is **1,024 bytes** (512 samples × 2 bytes, 16-bit
little-endian mono). Send frames at **real-time cadence** for best VAD accuracy.

| Property        | 16 kHz                          | 8 kHz                           |
| --------------- | ------------------------------- | ------------------------------- |
| Encoding        | PCM signed 16-bit little-endian | PCM signed 16-bit little-endian |
| Sample rate     | 16,000 Hz                       | 8,000 Hz                        |
| Channels        | 1 (mono)                        | 1 (mono)                        |
| Bytes per frame | 1,024                           | 1,024                           |
| Frame duration  | 32 ms                           | 64 ms                           |

`GnaniSTTService` also accepts **44,100 Hz** and **48,000 Hz** sample rates
(`x-sample-rate` header). The server resamples internally — still send 1,024-byte
frames at the appropriate cadence. See [STT Realtime — PCM
Specification](https://docs.gnani.ai/api/STT/stt-websocket#pcm-specification).

## Usage

### Streaming (WebSocket)

```python
import os

from pipecat.transcriptions.language import Language
from pipecat_gnani import GnaniSTTService

stt = GnaniSTTService(
    api_key=os.getenv("GNANI_API_KEY"),
    sample_rate=16000,
    settings=GnaniSTTService.Settings(
        language=Language.HI_IN,
    ),
)

# ... add stt to your pipeline
```

### REST (file-based)

```python
import os

from pipecat.transcriptions.language import Language
from pipecat_gnani import GnaniHttpSTTService

stt = GnaniHttpSTTService(
    api_key=os.getenv("GNANI_API_KEY"),
    aiohttp_session=session,
    settings=GnaniHttpSTTService.Settings(
        language=Language.HI_IN,
    ),
)

# ... add stt to your pipeline (VAD required)
```

### Automatic language detection

With `prisma-v3.0`, `language="indic-auto"` detects the language of each
utterance. Pass `language_candidates` to narrow the choice:

```python
import os

from pipecat.transcriptions.language import Language
from pipecat_gnani import GnaniSTTService

stt = GnaniSTTService(
    api_key=os.getenv("GNANI_API_KEY"),
    settings=GnaniSTTService.Settings(
        model="prisma-v3.0",
        language="indic-auto",
        language_candidates=[Language.HI_IN, Language.EN_IN],
        keywords=["Gnani", "Vachana"],
    ),
)

# ... add stt to your pipeline
```

<Tip>
  Without `language_candidates`, `"indic-auto"` can misidentify the language of
  short utterances that end in silence. Candidates, or a fixed `language`, are
  more reliable.
</Tip>

## Notes

- **Detected language**: `TranscriptionFrame.language` is the language Gnani
  reports for that transcript when available, and the configured `language`
  otherwise. With `"indic-auto"`, it follows a caller who switches language.

## Compatibility

Tested with the latest **Pipecat** main branch (**v1.5.0+**) using `pipecat-gnani`. Requires **`gnani-vachana` >= 0.9.0**. Check the [source repository](https://github.com/Gnani-AI-Mintlify/pipecat-gnani) for the latest tested version and changelog.
