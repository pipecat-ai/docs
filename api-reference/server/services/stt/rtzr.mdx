## Overview

`RTZRSTTService` provides streaming speech-to-text through
[RTZR](https://rtzr.ai/) (Return Zero) VITO, a Korean speech recognition API.
Its `sommers_ko` model is tuned for Korean telephone audio, which suits
call-center voice agents. The service extends Pipecat's `WebsocketSTTService`
and pushes `InterimTranscriptionFrame` and `TranscriptionFrame` results into
the pipeline. When the VAD reports the end of speech it sends `Finalize`, so
the utterance closes right away instead of waiting for RTZR's own end-point
detection.

## Installation

This is a community-maintained package distributed separately from `pipecat-ai`:

```bash
uv add pipecat-rtzr
```

or with pip:

```bash
pip install pipecat-rtzr
```

## Prerequisites

### RTZR Account Setup

Before using the RTZR STT service, you need:

1. **RTZR Account**: Sign up at the [RTZR Developers Console](https://developers.rtzr.ai/)
2. **Client ID and Secret**: Create a client in the console

### Required Environment Variables

- `RTZR_CLIENT_ID`: Your RTZR client ID
- `RTZR_CLIENT_SECRET`: Your RTZR client secret

The service exchanges them for an access token, caches it, and refreshes it
before it expires.

## Configuration

<ParamField path="client_id" type="str" default="None">
  RTZR client ID. Defaults to the `RTZR_CLIENT_ID` environment variable.
</ParamField>

<ParamField path="client_secret" type="str" default="None">
  RTZR client secret. Defaults to the `RTZR_CLIENT_SECRET` environment
  variable.
</ParamField>

<ParamField path="api_base" type="str" default="https://openapi.vito.ai">
  Base URL of the RTZR OpenAPI. The WebSocket URL is derived from it.
</ParamField>

<ParamField path="sample_rate" type="int" default="None">
  Sample rate of the incoming audio in Hz (8000 to 48000). If `None`, uses the
  pipeline's input sample rate. 8 kHz is the native telephony rate.
</ParamField>

<ParamField path="vad_force_finalize" type="bool" default="True">
  Send `Finalize` when the VAD reports the end of speech. Without it, an
  utterance cut off mid-speech is not finalized until the stream ends.
</ParamField>

<ParamField path="eos_flush_timeout" type="float" default="2.0">
  Seconds to wait for the last transcript after `EOS` on shutdown, when an
  utterance is still open. `0` closes right after sending `EOS`.
</ParamField>

<ParamField path="settings" type="RTZRSTTService.Settings" default="None">
  Runtime-updatable settings. See [Settings](#settings) below.
</ParamField>

<ParamField path="ttfs_p99_latency" type="float" default="None">
  P99 latency from speech end to final transcript, in seconds, used by turn
  strategies. This value has not been measured for Pipecat, so Pipecat's default
  applies if `None`. Measure your deployment with
  [stt-benchmark](https://github.com/pipecat-ai/stt-benchmark) and pass the
  result.
</ParamField>

### Settings

Runtime-configurable settings passed via the `settings` constructor argument
using `RTZRSTTService.Settings(...)`. These can be updated mid-conversation with
`STTUpdateSettingsFrame`; a change reconnects the stream, because RTZR reads
them from the connection URL.

| Parameter               | Type                                     | Default        | Description                                                                                                                           |
| ----------------------- | ---------------------------------------- | -------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| `model`                 | `str`                                    | `"sommers_ko"` | `"sommers_ko"`, `"sommers_ja"`, or `"whisper"`.                                                                                       |
| `language`              | `Language \| str \| None`                | `Language.KO`  | Sent only for the `"whisper"` model.                                                                                                  |
| `domain`                | `str`                                    | `"CALL"`       | `"CALL"` (telephony) or `"MEETING"`.                                                                                                  |
| `use_itn`               | `bool`                                   | `True`         | Inverse text normalization, such as numbers and dates.                                                                                |
| `use_disfluency_filter` | `bool`                                   | `False`        | Drop filler words.                                                                                                                    |
| `use_profanity_filter`  | `bool`                                   | `False`        | Mask profanity.                                                                                                                       |
| `use_punctuation`       | `bool`                                   | `False`        | Add punctuation to transcripts.                                                                                                       |
| `keywords`              | `list[str \| tuple[str, float]] \| None` | `None`         | Words to boost, as `"word"` or `("word", score)` with a score from -5.0 to 5.0. Up to 100 words of 20 characters. `sommers_ko` only. |
| `epd_time`              | `float \| None`                          | `None`         | End-point detection silence in seconds. The server default applies if `None`.                                                         |
| `noise_threshold`       | `float \| None`                          | `None`         | Noise gate threshold. The server default applies if `None`.                                                                           |
| `active_threshold`      | `float \| None`                          | `None`         | Speech activity threshold. The server default applies if `None`.                                                                      |

## Usage

### Basic Setup

```python
import os

from pipecat_rtzr import RTZRSTTService

stt = RTZRSTTService(
    client_id=os.getenv("RTZR_CLIENT_ID"),
    client_secret=os.getenv("RTZR_CLIENT_SECRET"),
)

# ... add stt to your pipeline, after a VAD
```

### With Punctuation and Keyword Boosting

```python
from pipecat_rtzr import RTZRSTTService

stt = RTZRSTTService(
    settings=RTZRSTTService.Settings(
        use_punctuation=True,
        keywords=[("리턴제로", 3.0), "상담원"],
    ),
)
```

## Notes

- **Audio format**: The service sends 16-bit mono PCM (`LINEAR16`).
- **Reconnects**: If the socket drops, the service reconnects automatically. The
  utterance in progress when it dropped is lost, because audio is not replayed.
- **Idle connections**: RTZR can close a connection that receives no audio for
  60 seconds, so the service sends silent audio as a keepalive.
- **Concurrency**: Streaming channels are limited by your RTZR plan.

## Compatibility

Tested with Pipecat 1.13.0 and Python 3.11 and 3.12.
