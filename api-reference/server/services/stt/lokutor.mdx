## Overview

`LokutorSTTService` streams audio to [Lokutor](https://lokutor.com)'s real-time
recogniser (`wss://api.lokutor.com/ws/stt`) and pushes `InterimTranscriptionFrame`
and `TranscriptionFrame` results. One model covers nine languages (`en`, `es`,
`ca`, `gl`, `eu`, `pt`, `fr`, `it`, `de`), and the language can be set or left
for the service to detect.

## Installation

This is a community-maintained package distributed separately from `pipecat-ai`:

```bash
uv add pipecat-lokutor
```

## Prerequisites

1. **Lokutor Account**: Sign up and get an API key at [app.lokutor.com](https://app.lokutor.com)
2. **Audio input at 16 kHz mono** (Pipecat's default). The service refuses to
   start on any other input rate; set `audio_in_sample_rate=16000` in
   `PipelineParams`.

### Required Environment Variables

- `LOKUTOR_API_KEY`: Your Lokutor API key

## Configuration

<ParamField path="api_key" type="str" required>
  Lokutor API key (or a short-lived `wst_` ticket) used to authenticate the
  WebSocket connection.
</ParamField>

<ParamField path="base_url" type="str" default="wss://api.lokutor.com/ws/stt">
  WebSocket URL of the STT endpoint.
</ParamField>

<ParamField path="sample_rate" type="int" default="None">
  Must be `16000` or `None` (use the pipeline's rate, which must be 16 kHz).
</ParamField>

<ParamField path="finalize_on_vad_stop" type="bool" default="True">
  Send `end` as soon as Pipecat's VAD reports that the user stopped speaking, so
  the final transcript arrives promptly; the socket is then reopened for the
  next utterance. Set to `False` to rely on the server's own end-of-utterance
  detection (about 0.7 s of silence).
</ParamField>

<ParamField path="settings" type="LokutorSTTService.Settings" default="None">
  Runtime settings. See [Settings](#settings) below.
</ParamField>

<ParamField path="ttfs_p99_latency" type="float" default="None">
  P99 time from end of speech to final transcript, in seconds. Measure it for
  your setup with the [Pipecat STT
  benchmark](https://github.com/pipecat-ai/stt-benchmark).
</ParamField>

### Settings

| Parameter  | Type        | Default | Description                                                             |
| ---------- | ----------- | ------- | ----------------------------------------------------------------------- |
| `language` | `Language`  | `EN`    | Language of the audio. `None` lets the service detect it.               |
| `keyterms` | `list[str]` | `None`  | Custom vocabulary (up to 100 names or terms), written as you want them. |

## Usage

```python
import os

from pipecat.pipeline.pipeline import Pipeline
from pipecat.transcriptions.language import Language
from pipecat_lokutor import LokutorSTTService

stt = LokutorSTTService(
    api_key=os.getenv("LOKUTOR_API_KEY"),
    settings=LokutorSTTService.Settings(
        language=Language.ES,
        keyterms=["Lokutor", "Pipecat"],
    ),
)

pipeline = Pipeline([
    transport.input(),
    stt,
    context_aggregator.user(),
    llm,
    tts,
    transport.output(),
    context_aggregator.assistant(),
])
```
