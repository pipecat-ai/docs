## Overview

`SpragSTTService` provides real-time speech-to-text transcription using [Sprag](https://sprag.ai)'s OpenAI-compatible WebSocket API.

## Installation

This is a community-maintained package distributed separately from `pipecat-ai`.

```bash
uv add pipecat-sprag
```

## Prerequisites

### Sprag Account Setup

Before using Sprag STT services, you need:

1. **Sprag Account**: Sign up at [sprag.ai](https://sprag.ai/auth/signup)
2. **API Key**: Generate an API key in the [Sprag app](https://sprag.ai/app/api-keys)

### Required Environment Variables

- `SPRAG_API_KEY`: Your Sprag API key. May be passed directly via the `api_key` constructor argument instead.

## Configuration

<ParamField path="api_key" type="str" default="None">
  Sprag API key. Falls back to the `SPRAG_API_KEY` environment variable.
</ParamField>

<ParamField
  path="base_url"
  type="str"
  default="wss://api.sprag.ai/v1/audio/transcriptions"
>
  Sprag streaming transcription WebSocket URL.
</ParamField>

<ParamField path="turn_detection" type="dict | Literal[False] | None" default="False">
  Turn detection mode. `False` uses the pipeline's VAD. `{"type": "server_vad"}` uses Sprag's server-side VAD.
</ParamField>

<ParamField path="settings" type="SpragSTTService.Settings" default="None">
  Runtime-configurable settings. The model defaults to `"rhythm"`.
</ParamField>

<Note>
  See the [source repository](https://github.com/sprag-ai/pipecat-sprag) for the
  authoritative, up-to-date list of settings and defaults.
</Note>

## Usage

```python
from pipecat_sprag.stt import SpragSTTService

stt = SpragSTTService()
```

```python
pipeline = Pipeline([
    transport.input(),
    stt,
    user_aggregator,
    llm,
    tts,
    transport.output(),
    assistant_aggregator,
])
```

## Compatibility

Tested with Pipecat v1.12.0 (`pipecat-ai>=1.8,<2`). Check the [source repository](https://github.com/sprag-ai/pipecat-sprag) for the latest tested version and changelog.
