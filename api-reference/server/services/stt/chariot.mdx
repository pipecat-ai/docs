## Overview

`ChariotSTTService` transcribes speech in real time using
[Chariot](https://chariot.in), for English and Indian languages, including
speech that mixes them.

The service streams the user's audio over one WebSocket and pushes interim
transcripts while they speak and a final transcript per utterance. By default
Pipecat's VAD decides when an utterance ends, and the transcript that answers is
marked final, so the turn ends without waiting out a timeout.

## Installation

```bash
uv add pipecat-chariot
```

## Prerequisites

1. Create an account at [platform.chariot.in](https://platform.chariot.in). New accounts include free credits.
2. Copy an API key from the console and set `CHARIOT_API_KEY`.

## Configuration

<ParamField path="api_key" type="str" required>
  Chariot API key.
</ParamField>

<ParamField path="sample_rate" type="int" default="None">
  Input rate in Hz, one of 8000, 16000, 22050, 24000, 32000, 44100 or 48000.
  Defaults to the pipeline's input rate.
</ParamField>

<ParamField path="commit_strategy" type="str" default="manual">
  `manual` finalizes each utterance when Pipecat's VAD hears the user stop.
  `vad` lets Chariot's server side voice detection split utterances.
</ParamField>

<ParamField path="vad_threshold" type="float" default="None">
  Server VAD speech threshold, 0.05 to 0.95. `commit_strategy="vad"` only.
</ParamField>

<ParamField path="silence_duration_ms" type="int" default="None">
  Server VAD silence that ends an utterance, 100 to 10000 ms. `commit_strategy="vad"` only.
</ParamField>

<ParamField path="min_speech_duration_ms" type="int" default="None">
  Server VAD minimum speech length, 0 to 5000 ms. `commit_strategy="vad"` only.
</ParamField>

<ParamField path="prefix_padding_ms" type="int" default="None">
  Server VAD audio kept before detected speech, 0 to 2000 ms. `commit_strategy="vad"` only.
</ParamField>

<ParamField path="ttfs_p99_latency" type="float" default="None">
  P99 seconds from end of speech to final transcript, used to time turn ends.
  Defaults to 0.6 for `balanced` and 0.8 for `high_accuracy`, plus the silence
  window with `vad`.
</ParamField>

<ParamField path="include_timestamps" type="bool" default="False">
  Word timestamps, in each transcription frame's `result["words"]`.
</ParamField>

### Settings

Pass these through `ChariotSTTService.Settings(...)`. Updating them with
`STTUpdateSettingsFrame` reconnects.

| Parameter  | Type       | Default                  | Description                                                                                                          |
| ---------- | ---------- | ------------------------ | -------------------------------------------------------------------------------------------------------------------- |
| `language` | `Language` | detected                 | English, Hindi, Bengali, Gujarati, Kannada, Malayalam, Marathi, Odia, Punjabi, Sanskrit, Tamil or Telugu.            |
| `mode`     | `str`      | `balanced`               | `high_accuracy` is more accurate; interim transcripts update less often and the final one takes about 0.15 s longer. |
| `style`    | `str`      | `codemix`                | `codemix` keeps English words in Latin script; `native` uses the language's own script.                              |
| `model`    | `str`      | `chariot-1-asr-realtime` | The real-time model.                                                                                                 |

## Usage

```python
import os

from pipecat.transcriptions.language import Language
from pipecat_chariot import ChariotSTTService

stt = ChariotSTTService(
    api_key=os.getenv("CHARIOT_API_KEY"),
    settings=ChariotSTTService.Settings(language=Language.HI),
)
```

<Note>
  Speech-to-text is billed per second of audio sent. A voice agent streams audio
  for the whole call, silence included, so a call is billed for its full length.
</Note>
