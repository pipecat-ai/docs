## Overview

`AWSTranscribeSTTService` provides real-time speech recognition using Amazon Transcribe's WebSocket streaming API with support for interim results, multiple languages, and configurable audio processing parameters for enterprise-grade transcription.

## Installation

To use AWS Transcribe services, install the required dependency:

```bash
uv add "pipecat-ai[aws]"
```

## Prerequisites

### AWS Account Setup

Before using AWS Transcribe STT services, you need:

1. **AWS Account**: Sign up at [AWS Console](https://console.aws.amazon.com/)
2. **IAM User**: Create an IAM user with Amazon Transcribe permissions
3. **Credentials**: Set up AWS access keys and region configuration

### Required Environment Variables

- `AWS_ACCESS_KEY_ID`: Your AWS access key ID
- `AWS_SECRET_ACCESS_KEY`: Your AWS secret access key
- `AWS_SESSION_TOKEN`: Session token (if using temporary credentials)
- `AWS_REGION`: AWS region (defaults to "us-east-1")

<ParamField path="api_key" type="str | None" default="None">
  AWS secret access key. If `None`, falls back to environment variables and the

  SSO, etc.). Temporary credentials from the chain are renewed automatically
  before they expire.
</ParamField>

<ParamField path="aws_access_key_id" type="str | None" default="None">
  AWS access key ID. Same fallback behaviour as `api_key`.
</ParamField>

<ParamField path="aws_session_token" type="str | None" default="None">
  AWS session token for temporary credentials.
</ParamField>

<ParamField path="region" type="str | None" default="None">
  AWS region for the service. If `None`, uses `AWS_REGION` environment variable
  (defaults to `"us-east-1"`).
</ParamField>

<ParamField path="sample_rate" type="int | None" default="None">
  Audio sample rate in Hz. When `None`, uses the pipeline's configured sample
  rate. AWS Transcribe only supports `8000` or `16000` Hz. Any other rate is
  resampled to `16000` Hz before it's sent.
</ParamField>

<ParamField path="language" type="Language | None" default="None" deprecated>

  `settings=AWSTranscribeSTTService.Settings(language=...)` instead.
</ParamField>

<ParamField
  path="settings"
  type="AWSTranscribeSTTService.Settings"
  default="None"

  Runtime-configurable settings for the STT service. See [Settings](#settings)
  below.
</ParamField>

<ParamField
  path="ttfs_p99_latency"
  type="float | None"

>
  P99 latency from speech end to final transcript in seconds. Override for your
  deployment.
</ParamField>

### Settings

Runtime-configurable settings passed via the `settings` constructor argument using `AWSTranscribeSTTService.Settings(...)`. These can be updated mid-conversation with `STTUpdateSettingsFrame`. See [Service Settings](/pipecat/fundamentals/service-settings) for details.

| Parameter                   | Type                          | Default       | Description                                                                                                                                                                                                                                                                                                                                                      |
| --------------------------- | ----------------------------- | ------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `model`                     | `str \| None`                 | `None`        | Not sent by this service; reported only as the model name in metrics and traces. _(Inherited from base STT settings.)_                                                                                                                                                                                                                                           |
| `language`                  | `Language \| str`             | `Language.EN` | Language for transcription. See [AWS Transcribe supported languages](https://docs.aws.amazon.com/transcribe/latest/dg/supported-languages.html). _(Inherited from base STT settings.)_                                                                                                                                                                           |
| `partial_results_stability` | `"high" \| "medium" \| "low"` | `"high"`      | How stable interim results should be, trading accuracy against latency: `"low"` is the most accurate, `"high"` the fastest. AWS binds this to a connection, so updating it at runtime triggers a reconnect. See [AWS partial result stabilization docs](https://docs.aws.amazon.com/transcribe/latest/dg/streaming.html#streaming-partial-result-stabilization). |
| `show_speaker_label`        | `bool`                        | `False`       | Enable speaker diarization. Each contiguous speaker run of a final result is pushed as its own frame, with AWS's speaker label (`"0"`, `"1"`, ...) in `speaker.label`. Interim results have no `speaker`. Updating it at runtime triggers a reconnect.                                                                                                           |
| `speaker_format`            | `str \| None`                 | `None`        | Format string for diarized speaker runs. Use `{speaker}` for the speaker label, `{speaker_number}` for the speaker's order of first appearance (`1`, `2`, ...), and `{text}` for the transcript text, e.g. `"{speaker}: {text}"`. If `None`, the text is not modified. Updating it at runtime does not reconnect.                                                |
| `language_options`          | `list[Language] \| None`      | `None`        | Languages AWS chooses among to identify the spoken language: at least two, one locale per language (`Language.EN_US` and `Language.EN_GB` can't both be listed), and AWS recommends no more than five. When set, any configured `language` is ignored and each transcription frame carries the language AWS identified. Updating it at runtime triggers a reconnect. See [AWS language identification docs](https://docs.aws.amazon.com/transcribe/latest/dg/lang-id-stream.html). |
| `identify_multiple_languages` | `bool`                      | `False`       | Identify the language of each segment, for speakers who switch languages mid-conversation. Requires `language_options`. Updating it at runtime triggers a reconnect. |
| `preferred_language`        | `Language \| None`            | `None`        | The most likely of `language_options`, which helps AWS identify the language sooner. Requires `language_options`. Updating it at runtime triggers a reconnect. |

## Usage

### Basic Setup

```python
import os

from pipecat.services.aws.stt import AWSTranscribeSTTService

stt = AWSTranscribeSTTService(
    api_key=os.getenv("AWS_SECRET_ACCESS_KEY"),
    aws_access_key_id=os.getenv("AWS_ACCESS_KEY_ID"),
    region=os.getenv("AWS_REGION", "us-east-1"),
)
```

### With Custom Language and Sample Rate

```python
from pipecat.services.aws.stt import AWSTranscribeSTTService
from pipecat.transcriptions.language import Language

stt = AWSTranscribeSTTService(
    api_key=os.getenv("AWS_SECRET_ACCESS_KEY"),
    aws_access_key_id=os.getenv("AWS_ACCESS_KEY_ID"),
    region="eu-west-1",
    sample_rate=8000,
    settings=AWSTranscribeSTTService.Settings(
        language=Language.ES,
    ),
)
```

### With Language Identification

```python
stt = AWSTranscribeSTTService(
    api_key=os.getenv("AWS_SECRET_ACCESS_KEY"),
    aws_access_key_id=os.getenv("AWS_ACCESS_KEY_ID"),
    settings=AWSTranscribeSTTService.Settings(
        language_options=[Language.EN_US, Language.ES_US],
        preferred_language=Language.EN_US,
    ),
)
```

## Notes

- **Pre-signed URL authentication**: The service uses pre-signed URLs for WebSocket authentication rather than passing credentials directly, following AWS best practices.
- **Invalid language identification settings**: `identify_multiple_languages` and `preferred_language` require `language_options`, and `language_options` needs at least two languages, and `preferred_language` must be one of them. The constructor raises `ValueError` on a conflict; a conflicting runtime update is rejected whole with a non-fatal error.

## Event Handlers

AWS Transcribe STT supports the standard [service connection events](/api-reference/server/events/service-events):

| Event                 | Description                                |
| --------------------- | ------------------------------------------ |
| `on_connected`        | Connected to AWS Transcribe WebSocket      |
| `on_disconnected`     | Disconnected from AWS Transcribe WebSocket |
| `on_connection_error` | Connection error occurred                  |

```python
@stt.event_handler("on_connected")
async def on_connected(service):
    print("Connected to AWS Transcribe")
```
