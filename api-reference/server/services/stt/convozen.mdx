## Overview

ConvoZen's Akshara models transcribe nine Indian languages, including code-mixed
speech. `ConvozenSTTService` transcribes one complete utterance per request, so
it extends `SegmentedSTTService` and segments audio with the pipeline's VAD
rather than streaming.

## Installation

This is a community-maintained package distributed separately from `pipecat-ai`:

```bash
uv add pipecat-convozen
```

## Prerequisites

### ConvoZen Account Setup

Before using ConvoZen STT, you need:

1. **ConvoZen Account**: Sign up at [ConvoZen](https://convozen.ai/)
2. **API Key**: Generate an API key from your [account dashboard](https://app.convozen.ai/developers/models)

### Required Environment Variables

- `CONVOZEN_API_KEY`: Your ConvoZen API key for authentication

## Configuration

<ParamField path="api_key" type="str" required>
  ConvoZen API key for authentication.
</ParamField>

<ParamField path="aiohttp_session" type="aiohttp.ClientSession" required>
  The bot's shared aiohttp session, used for every request to ConvoZen. Create
  one per bot with `async with aiohttp.ClientSession() as session:` and pass the
  same session to each HTTP service, so connections are pooled and closed once.
</ParamField>

<ParamField path="model" type="str" default="akshara-pro">
  Akshara model to use. Allowed values: `"akshara-pro"`, `"akshara"`.
</ParamField>

<ParamField
  path="base_url"
  type="str"
  default="https://voice.convozen.ai/sdk-models/developer-api/api"
>
  API base URL. Override to reach a self-hosted deployment.
</ParamField>

<ParamField path="ttfs_p99_latency" type="float" default="CONVOZEN_TTFS_P99">
  P99 latency from speech end to final transcript in seconds. Override for your
  deployment. See [stt-benchmark](https://github.com/pipecat-ai/stt-benchmark).
</ParamField>

<ParamField path="settings" type="ConvozenSTTService.Settings" default="None">
  Runtime-configurable settings for the STT service. See [Settings](#settings)
  below.
</ParamField>

### Settings

Runtime-configurable settings passed via the `settings` constructor argument using `ConvozenSTTService.Settings(...)`. These can be updated mid-conversation with `STTUpdateSettingsFrame`. See [Service Settings](/pipecat/fundamentals/service-settings) for details.

| Parameter         | Type              | Default | Description                                                                                                                                               |
| ----------------- | ----------------- | ------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `model`           | `str`             | `None`  | STT model identifier. _(Inherited from base STT settings.)_                                                                                               |
| `language`        | `Language \| str` | `None`  | Language of the audio. _(Inherited from base STT settings.)_ Also supplies the default language hint.                                                     |
| `lang_tags`       | `list[str]`       | `None`  | Language hints, for example `["hi", "en"]` for code-mixed speech. Overrides the hint derived from `language`.                                             |
| `keywords`        | `list[str]`       | `None`  | Domain words to bias recognition towards, such as names and product terms.                                                                                |
| `blank_penalty`   | `float`           | `None`  | Penalizes blank/silence tokens; increase it to reduce empty gaps in the transcript. Unbounded. `None` lets the server derive one from the language hints. |
| `word_timestamps` | `bool`            | `False` | Request per-word timings in the response payload.                                                                                                         |

## Usage

### Basic Setup

```python
import aiohttp
from pipecat_convozen import ConvozenSTTService
from pipecat.transcriptions.language import Language

async with aiohttp.ClientSession() as session:
    stt = ConvozenSTTService(
        api_key=os.getenv("CONVOZEN_API_KEY"),
        aiohttp_session=session,
    )
```

### With Language and Keywords

```python
stt = ConvozenSTTService(
    api_key=os.getenv("CONVOZEN_API_KEY"),
    aiohttp_session=session,
    settings=ConvozenSTTService.Settings(
        language=Language.HI,
        keywords=["ConvoZen", "Akshara"],
    ),
)
```

### Code-Mixed Speech

```python
stt = ConvozenSTTService(
    api_key=os.getenv("CONVOZEN_API_KEY"),
    aiohttp_session=session,
    settings=ConvozenSTTService.Settings(
        language=Language.HI,
        lang_tags=["hi", "en"],
    ),
)
```

See the [source repository](https://github.com/convozen/pipecat-convozen) for a
complete runnable example wiring a transport → STT → LLM → TTS.

## Notes

- **Supported models**: `akshara-pro` (default) and `akshara`.
- **Supported languages**: Bengali (bn), English (en), Gujarati (gu), Hindi (hi), Kannada (kn), Malayalam (ml), Marathi (mr), Tamil (ta), and Telugu (te). Regional variants such as `hi-IN` map to their base code. A language outside this set is sent without a hint rather than as one the server would reject.
- **VAD required**: Akshara transcribes complete utterances and emits no interim results, so the service extends `SegmentedSTTService` and needs a VAD analyzer in the pipeline to mark utterance boundaries.
- **Transcription confidence**: Akshara returns a `score` alongside the transcript. It is an unbounded log-probability where values closer to zero are better, not a `[0, 1]` confidence, and it is available on the `TranscriptionFrame` `result` payload rather than as a confidence value.
- **Single speaker**: Audio is always submitted as mono. Speaker diarization is not exposed, since it returns a different response shape.
