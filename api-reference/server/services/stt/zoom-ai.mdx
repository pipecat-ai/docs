## Overview

`ZoomAISTTService` streams audio to Zoom Scribe Live over a WebSocket. Scribe's own voice activity detection decides when the user starts and stops speaking: the service broadcasts `ProposedUserStartedSpeakingFrame` when speech starts, then pushes each completed transcript as a `TranscriptionFrame` followed by `ProposedUserStoppedSpeakingFrame`. It recommends `ExternalUserTurnStrategies` to resolve those proposals.

Settings map to the Scribe API fields of the same name. For what each feature does, and its availability, pricing, and enablement, see the [Scribe documentation](https://developers.zoom.us/docs/ai-services/scribe/) and [zoom.ai](https://www.zoom.ai/).

## Installation

To use Zoom AI services, install the required dependency:

```bash
uv add "pipecat-ai[zoom-ai]"
```

## Prerequisites

### Zoom AI Account Setup

Before using Zoom AI STT, you need:

1. **Zoom AI Services access**: Sign up through [Zoom AI Services](https://www.zoom.ai/)
2. **API key**: A Zoom AI Services API key or JWT

### Required Environment Variables

- `ZOOM_AI_API_KEY`: Your Zoom AI Services API key

## Configuration

### ZoomAISTTService

<ParamField path="api_key" type="str" required>
  Zoom AI Services API key or JWT. It is sent on every request and reconnect, so
  it must stay valid for as long as the service runs.
</ParamField>

<ParamField
  path="url"
  type="str"
  default="wss://api.zoom.us/v2/aiservices/scribe/live"
>
  Scribe Live WebSocket URL. A plaintext `ws://` URL to a host other than
  localhost logs a warning, since the API key and audio are sent unencrypted.
</ParamField>

<ParamField path="sample_rate" type="int | None" default="None">
  Input audio sample rate in Hz. If `None`, uses the pipeline's audio sample
  rate. Audio is resampled to 16 kHz, the only rate Scribe Live accepts.
</ParamField>

<ParamField path="should_interrupt" type="bool" default="True">
  Whether a user turn started by Scribe interrupts the bot.
</ParamField>

<ParamField path="settings" type="ZoomAISTTService.Settings" default="None">
  Runtime-configurable settings for the STT service. See [Settings](#settings)
  below.
</ParamField>

### Settings

Runtime-configurable settings passed via the `settings` constructor argument using `ZoomAISTTService.Settings(...)`. Changing a setting reconnects with a new Scribe session. See [Service Settings](/pipecat/fundamentals/service-settings) for details.

| Parameter            | Type                    | Default         | Description                                                                                                                                                                                                                                                                                                                    |
| -------------------- | ----------------------- | --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `model`              | `str \| None`           | `None`          | STT model identifier. _(Inherited from base STT settings.)_                                                                                                                                                                                                                                                                    |
| `language`           | `Language \| str`       | `Language.EN_US` | Expected language of the audio. _(Inherited from base STT settings.)_ Regional variants Scribe doesn't list resolve to the locale of their base language. See the [Scribe documentation](https://developers.zoom.us/docs/ai-services/scribe/speech-understanding/) for the languages each model supports.                  |
| `silence_duration_ms` | `int \| None`          | `350`           | Milliseconds of silence that end a turn in Scribe's voice activity detection. Lower is faster; higher keeps sentences with longer pauses together. For transcription without an agent, a longer value such as `600` can improve accuracy. `None` uses Scribe's default.                                                        |
| `diarization`        | `bool \| None`          | `False`         | Whether Scribe labels each completed transcript with a speaker. The labels are in the Scribe event attached as `TranscriptionFrame.result`: `speaker`, plus `speaker_segments` with each one's span when several speakers spoke. Scribe's speaker tags are removed from the transcript text.                                   |
| `language_detection` | `str \| None`           | `None`          | Scribe language detection mode (`config.language_detection.mode`). `None` turns it off. The language Scribe detects is in `TranscriptionFrame.language`, which is `None` when Scribe reports none.                                                                                                                              |
| `vocabulary`         | `list[str] \| None`     | `None`          | Words and phrases that customize recognition (`config.vocabulary.phrases`).                                                                                                                                                                                                                                                    |
| `text_polishing`     | `bool \| None`          | `False`         | Whether to use Scribe's text polishing (`outputs.text_polishing`). The polished text is the transcript, and the recognized text is in `TranscriptionFrame.result` (`transcript`). If polishing fails, the recognized text is used.                                                                                             |
| `extra`              | `dict[str, Any]`        | `{}`            | Scribe request fields that have no setting, shaped like the request (for example `{"config": {"profanity_filter": True}}`). Merged into the session configuration over the settings above, except that `audio.format` stays `pcm16`.                                                                                          |

## Usage

### Basic Setup

```python
import os

from pipecat.services.zoom_ai.stt import ZoomAISTTService

stt = ZoomAISTTService(
    api_key=os.getenv("ZOOM_AI_API_KEY"),
)
```

### With Settings

```python
from pipecat.services.zoom_ai.stt import ZoomAISTTService
from pipecat.transcriptions.language import Language

stt = ZoomAISTTService(
    api_key=os.getenv("ZOOM_AI_API_KEY"),
    settings=ZoomAISTTService.Settings(
        language=Language.EN_US,
        silence_duration_ms=500,
        diarization=True,
        vocabulary=["Pipecat", "Scribe"],
    ),
)
```

## Notes

- **Turn detection**: Scribe ends each turn, so don't add a local VAD turn strategy. The service recommends `ExternalUserTurnStrategies`. A transcript that arrives without a preceding speech start (for example right after a reconnect) opens its own turn, and a turn whose transcript is empty ends with no transcription.
- **Final transcripts only**: The service pushes final transcripts only, no interim results.
- **Audio format**: Scribe Live accepts 16 kHz mono PCM16 only. The service resamples input audio.
- **Idle sessions**: The service sends keepalive silence, because Scribe ends a session after 30 seconds without audio. Keepalive and gap-filling silence count toward usage.
- **Time to final segment (TTFS)**: Scribe defines the turn boundary, so the service reports no TTFS metric.

## Event Handlers

Zoom AI STT supports the standard [service connection events](/api-reference/server/events/service-events):

| Event             | Description                           |
| ----------------- | ------------------------------------- |
| `on_connected`    | Connected to Scribe Live WebSocket    |
| `on_disconnected` | Disconnected from Scribe Live WebSocket |

```python
@stt.event_handler("on_connected")
async def on_connected(service):
    print("Connected to Zoom Scribe")
```
