## Overview

`ZoomAISTTService` provides real-time speech recognition with the [Scribe API](https://developers.zoom.us/docs/ai-services/scribe/) from Zoom AI Services, streaming audio over a WebSocket in [Live mode](https://developers.zoom.us/docs/ai-services/scribe/live-mode/). Scribe detects when each user turn ends, so the service drives turn detection for live streaming without a local VAD. It supports Scribe's additional features, including English Pro model, multilingual models, language detection, speaker diarization, custom vocabulary, and text polishing, etc.

## Installation

To use Zoom AI services, install the required dependency:

```bash
uv add "pipecat-ai[zoom-ai]"
```

## Prerequisites

### Zoom AI Account Setup

Before using Zoom AI STT, you need:

1. **Zoom AI Services access**: Sign up through [Zoom AI Services](https://www.zoom.ai/)
2. **Credentials**: An API key, or a JWT created from it. See [Get credentials](https://developers.zoom.us/docs/ai-services/auth/).

### Required Environment Variables

- `ZOOM_AI_API_KEY`: Your Zoom AI Services API key

## Configuration

### ZoomAISTTService

<ParamField path="api_key" type="str" required>
  Zoom AI Services API key or JWT. It is sent on every connection and reconnect,
  so it must stay valid for as long as the service runs.
</ParamField>

<ParamField
  path="url"
  type="str"
  default="wss://api.zoom.us/v2/aiservices/scribe/live"
>
  Scribe Live WebSocket URL. A plaintext `ws://` URL to a host other than
  localhost logs a warning, since the API key and audio are sent unencrypted.
</ParamField>

<ParamField path="sample_rate" type="int | None" default="None">
  Input audio sample rate in Hz. If `None`, uses the pipeline's audio sample
  rate. Audio is resampled to 16 kHz for Scribe.
</ParamField>

<ParamField path="should_interrupt" type="bool" default="True">
  Whether a user turn started by Scribe interrupts the bot.
</ParamField>

<ParamField path="settings" type="ZoomAISTTService.Settings" default="None">
  Runtime-configurable settings for the STT service. See [Settings](#settings)
  below.
</ParamField>

### Settings

Runtime-configurable settings passed via the `settings` constructor argument using `ZoomAISTTService.Settings(...)`. Settings map to the Scribe API fields of the same name; see the [Scribe documentation](https://developers.zoom.us/docs/ai-services/scribe/) for what each feature does and its availability. See [Service Settings](/pipecat/fundamentals/service-settings) for how settings work in Pipecat.

| Parameter             | Type                | Default          | Description                                                                                                                                                                                                                                 |
| --------------------- | ------------------- | ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `model`               | `str \| None`       | `None`           | Recognition model, such as `zoom-scribe-en-pro` or `zoom-scribe-multilingual`. `None` lets Scribe choose a compatible model. See [Select a model](https://developers.zoom.us/docs/ai-services/scribe/speech-understanding/#select-a-model). |
| `language`            | `Language \| str`   | `Language.EN_US` | Language of the audio; with language detection, the preferred initial language.                                                                                                                                                             |
| `silence_duration_ms` | `int \| None`       | `350`            | Milliseconds of silence that end a turn. Pipecat's default is 350ms optimized for voice agent use case. `None` uses Scribe's default. See [Tuning Turn Detection](#tuning-turn-detection).                                                  |
| `diarization`         | `bool \| None`      | `False`          | Whether Scribe labels each transcript with its speaker. See [With Speaker Diarization](#with-speaker-diarization).                                                                                                                          |
| `language_detection`  | `str \| None`       | `None`           | Language detection mode; Live mode supports `"continuous"`. `None` turns it off. See [With the Multilingual Model](#with-the-multilingual-model).                                                                                           |
| `vocabulary`          | `list[str] \| None` | `None`           | [Custom vocabulary](https://developers.zoom.us/docs/ai-services/scribe/custom-vocabulary/): names, acronyms, and terms to recognize. See [With Custom Vocabulary](#with-custom-vocabulary).                                                 |
| `text_polishing`      | `bool \| None`      | `False`          | Whether to return [Text Polishing](https://developers.zoom.us/docs/ai-services/scribe/text-polishing/) output as the transcript. It supports only en-US. See [With Text Polishing](#with-text-polishing).                                   |
| `extra`               | `dict[str, Any]`    | `{}`             | Other Scribe fields, shaped like the [`session.update` event](https://developers.zoom.us/docs/ai-services/scribe/live-mode/). See [Passing Other Scribe Fields](#passing-other-scribe-fields).                                              |

## Usage

### Basic Setup

```python
import os

from pipecat.services.zoom_ai.stt import ZoomAISTTService

stt = ZoomAISTTService(
    api_key=os.getenv("ZOOM_AI_API_KEY"),
)
```

### Tuning Turn Detection

Scribe ends a turn after `silence_duration_ms` of silence. The default, 350 ms, is tuned for voice agents. Raise it to keep sentences with longer pauses together, at the cost of a later response; for transcription without an agent, a value such as 600 can improve accuracy.

```python
import os

from pipecat.services.zoom_ai.stt import ZoomAISTTService

stt = ZoomAISTTService(
    api_key=os.getenv("ZOOM_AI_API_KEY"),
    settings=ZoomAISTTService.Settings(
        silence_duration_ms=600,
    ),
)
```

### With Speaker Diarization

Enable [speaker diarization](https://developers.zoom.us/docs/ai-services/scribe/speech-understanding/) to label who spoke each transcript, for example in multi-party calls:

```python
import os

from pipecat.services.zoom_ai.stt import ZoomAISTTService

stt = ZoomAISTTService(
    api_key=os.getenv("ZOOM_AI_API_KEY"),
    settings=ZoomAISTTService.Settings(
        diarization=True,
    ),
)
```

Each `TranscriptionFrame` carries Scribe's event in `result`, with the speaker label in `result["speaker"]` (for example `"Speaker 1"`), and `result["speaker_segments"]` when several people spoke in one turn.

### With the Pro Model

`zoom-scribe-en-pro` is Scribe's higher-accuracy English model. It requires premium-model access on your account; see [Select a model](https://developers.zoom.us/docs/ai-services/scribe/speech-understanding/#select-a-model).

```python
import os

from pipecat.services.zoom_ai.stt import ZoomAISTTService
from pipecat.transcriptions.language import Language

stt = ZoomAISTTService(
    api_key=os.getenv("ZOOM_AI_API_KEY"),
    settings=ZoomAISTTService.Settings(
        model="zoom-scribe-en-pro",
        language=Language.EN_US,
    ),
)
```

### With the Multilingual Model

For callers who may switch languages, use `zoom-scribe-multilingual` with continuous language detection. `language` is the language Scribe expects first. Each `TranscriptionFrame` has the language Scribe detected for that transcript in `language`.

```python
import os

from pipecat.services.zoom_ai.stt import ZoomAISTTService
from pipecat.transcriptions.language import Language

stt = ZoomAISTTService(
    api_key=os.getenv("ZOOM_AI_API_KEY"),
    settings=ZoomAISTTService.Settings(
        model="zoom-scribe-multilingual",
        language=Language.EN_US,
        language_detection="continuous",
        # Optional: restrict detection to the languages you expect.
        extra={"config": {"language_detection": {"candidate_languages": ["en-US", "fr-FR"]}}},
    ),
)
```

See [Detect languages](https://developers.zoom.us/docs/ai-services/scribe/speech-understanding/#detect-languages) and [Multilingual model languages](https://developers.zoom.us/docs/ai-services/scribe/speech-understanding/#multilingual-model-languages) for the supported languages.

### With Custom Vocabulary

Add names, product terms, and acronyms that Scribe should recognize:

```python
import os

from pipecat.services.zoom_ai.stt import ZoomAISTTService

stt = ZoomAISTTService(
    api_key=os.getenv("ZOOM_AI_API_KEY"),
    settings=ZoomAISTTService.Settings(
        vocabulary=["Pipecat", "Zoom Scribe", "Kubernetes"],
    ),
)
```

See [Custom vocabulary](https://developers.zoom.us/docs/ai-services/scribe/custom-vocabulary/) for limits and for persistent vocabularies, which you can apply with `extra={"config": {"vocabulary_id": "..."}}` instead.

### With Text Polishing

[Text Polishing](https://developers.zoom.us/docs/ai-services/scribe/text-polishing/) turns spoken language into clear written text: it removes filler words, false starts, and repetition, and improves grammar and punctuation. The polished text becomes the transcript, and the original is in `TranscriptionFrame.result["transcript"]`. If polishing fails, the original transcript is used.

```python
import os

from pipecat.services.zoom_ai.stt import ZoomAISTTService

stt = ZoomAISTTService(
    api_key=os.getenv("ZOOM_AI_API_KEY"),
    settings=ZoomAISTTService.Settings(
        text_polishing=True,
    ),
)
```

Text Polishing is available for `en-US` and can't be combined with language detection. It adds latency, since Scribe may collect multiple VAD segments to run polishing.

### Passing Other Scribe Fields

Use `extra` for Scribe fields that have no setting. It is shaped like the `session.update` event and merged into it, so new Scribe features can be used without an immediate Pipecat update:

```python
import os

from pipecat.services.zoom_ai.stt import ZoomAISTTService

stt = ZoomAISTTService(
    api_key=os.getenv("ZOOM_AI_API_KEY"),
    settings=ZoomAISTTService.Settings(
        extra={"config": {"profanity_filter": True}},
    ),
)
```

The service keeps the audio format it sends (`audio.format` stays `pcm16`).

### Updating Settings Mid-Stream

Send an `STTUpdateSettingsFrame` to change settings during a conversation. The service reconnects with a new Scribe session once the current turn ends:

```python
from pipecat.frames.frames import STTUpdateSettingsFrame

await worker.queue_frame(
    STTUpdateSettingsFrame(
        delta=ZoomAISTTService.Settings(vocabulary=["Pipecat", "Order 1001"])
    )
)
```

## Notes

- **Final transcripts only**: The service pushes a final transcript per turn, with no interim results.
- **Idle sessions**: Scribe ends a session after 30 seconds without audio, so the service sends keepalive silence when input stops (see [Session limits](https://developers.zoom.us/docs/ai-services/scribe/live-mode/#session-limits)). Keepalive silence and the silence sent to end a turn count toward usage.
- **Errors**: If Zoom refuses the connection (for example, an invalid API key), the error includes Zoom's reason. If Scribe rejects the session's settings, the error has the `INVALID_REQUEST` category, since a new session would be rejected the same way. Errors include the session's tracking ID (`x-zm-trackingid`), which Zoom support uses to find a session. See [Error Handling](/pipecat/fundamentals/error-handling).
- **Time to final segment (TTFS)**: Scribe defines the turn boundary, so the service reports no TTFS metric.

## Event Handlers

Zoom AI STT supports the standard [service connection events](/api-reference/server/events/service-events):

| Event                 | Description                             |
| --------------------- | --------------------------------------- |
| `on_connected`        | Connected to Scribe Live WebSocket      |
| `on_disconnected`     | Disconnected from Scribe Live WebSocket |
| `on_connection_error` | Connection to Scribe Live failed        |

```python
@stt.event_handler("on_connected")
async def on_connected(service):
    print("Connected to Zoom Scribe")
```
