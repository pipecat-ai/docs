## Overview

`AudreySTTService` streams the user's audio to [Audrey](https://p99lab.com),
p99lab's speech-to-text model for phone calls, meetings and accented speech,
over a WebSocket. It pushes `InterimTranscriptionFrame` while the user speaks
and a `TranscriptionFrame` for each finalised utterance. When the pipeline has
a turn analyzer, the service asks the server to finalise the open utterance as
soon as the user's turn ends, instead of waiting for the server's own silence
endpointing.

## Installation

This is a community-maintained package distributed separately from `pipecat-ai`:

```bash
uv pip install git+https://github.com/P99Lab/pipecat-p99lab.git
```

## Prerequisites

### p99lab Account Setup

Before using the Audrey STT service, you need:

1. **p99lab Account**: Sign up at [console.p99lab.com](https://console.p99lab.com)
2. **API Key**: Create an API key in the console

### Required Environment Variables

- `P99LAB_API_KEY`: Your p99lab API key for authentication
- `P99LAB_API_URL` (optional): API base URL. Defaults to the public Audrey API,
  `https://api.p99lab.com`.

## Configuration

<ParamField path="api_key" type="str" default="None">
  p99lab API key. If `None`, read from the `P99LAB_API_KEY` environment
  variable.
</ParamField>

<ParamField path="base_url" type="str" default="None">
  API base URL (`https://...`; the stream URL `wss://.../v1/stream` is derived
  from it) or a full `wss://` stream URL. If `None`, read from
  `P99LAB_API_URL`, else the public Audrey API.
</ParamField>

<ParamField path="language" type="Language | str" default="en">
  Recognition language: English by default, 30 languages supported (`"fr"`, `"de"`, `"ja"`, ...;
  region codes such as `Language.PT_BR` are accepted). Turn detection and number formatting are English-only.
</ParamField>

<ParamField path="prompt" type="str" default="None">
  Context text, up to 500 characters: names, product terms, what the call is
  about.
</ParamField>

<ParamField path="endpoint_ms" type="int" default="600">
  Silence in milliseconds (200 to 3000) after which the server finalises an
  utterance by itself.
</ParamField>

<ParamField path="flush_on" type="str" default="turn">
  When to ask the server to finalise the current utterance at once: `"turn"`
  (at the end of the user's turn, when the pipeline has a turn analyzer),
  `"vad"` (at every VAD stop) or `"never"`.
</ParamField>

<ParamField path="sample_rate" type="int" default="None">
  Input sample rate. If `None`, uses the pipeline sample rate. Rates other than
  8, 16, 24 and 48 kHz are resampled to 16 kHz.
</ParamField>

<ParamField path="open_timeout" type="float" default="30.0">
  Seconds to wait for the WebSocket handshake.
</ParamField>

<ParamField path="settings" type="AudreySTTService.Settings" default="None">
  Runtime-updatable settings override, merged on top of the explicit kwargs
  above. See [Settings](#settings) below.
</ParamField>

### Settings

Runtime-configurable settings passed via the `settings` constructor argument
using `AudreySTTService.Settings(...)`. The settings dataclass extends
Pipecat's `STTSettings`. Changing any of them finishes the current session and
opens a new one, so no transcript is lost.

| Parameter     | Type  | Default | Description                                                     |
| ------------- | ----- | ------- | --------------------------------------------------------------- |
| `language`    | `str` | `"en"`  | Language for speech recognition.                                |
| `prompt`      | `str` | `None`  | Context text, up to 500 characters.                             |
| `endpoint_ms` | `int` | `600`   | Silence after which the server finalises an utterance.          |
| `partial_ms`  | `int` | `None`  | How often a partial is sent, in ms of new speech (250 to 5000). |

### Errors

Dropped connections and transient server errors are retried with backoff.
Account refusals are pushed as a permanent `ErrorFrame` whose `exception` is
an `AudreyAPIError` with `status` and `code`: 401 (unknown or revoked key), 402
(the account cannot pay; `reason` and `console_url` say how to fix it) and 429
for the key's daily limit.

## Usage

```python
from pipecat_p99lab import AudreySTTService

stt = AudreySTTService(
    language="en",
    prompt="Acme Dental, Dr. Okafor",
)

# ... add stt to your pipeline, between transport.input() and the user aggregator
```
