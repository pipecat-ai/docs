## Overview

`DeepdubSTTService` provides real-time English and Hebrew speech-to-text through
[Deepdub](https://deepdub.ai/). It extends Pipecat's `WebsocketSTTService`. Interim
results are pushed as `InterimTranscriptionFrame` and finals as `TranscriptionFrame`,
tagged with the language Deepdub detected.

By default, Pipecat's turn strategies decide when the user's turn ends. When a
`VADUserStoppedSpeakingFrame` arrives, the service asks Deepdub to finalize, and the
final transcript comes back with `finalized=True`. With
`vad_force_turn_endpoint=False`, Deepdub's endpoint detection decides instead.

The same package provides [Deepdub text-to-speech](/api-reference/server/services/tts/deepdub).

## Installation

This is a community-maintained package distributed separately from `pipecat-ai`:

```bash
uv add pipecat-deepdub
```

## Prerequisites

### Deepdub Account Setup

Before using the Deepdub STT service, you need:

1. **Deepdub Account**: Sign up at [Deepdub](https://deepdub.ai/)
2. **API Key**: Obtain your API key from your Deepdub account

### Required Environment Variables

- `DEEPDUB_API_KEY`: Your Deepdub API key

## Configuration

<ParamField path="api_key" type="str" required>
  Deepdub API key.
</ParamField>

<ParamField
  path="url"
  type="str"
  default="wss://wsgw.deepdub.ai/transcribe-websocket"
>
  Speech-to-text endpoint. Use `wss://wsgw.eu.deepdub.ai/transcribe-websocket`
  for the EU.
</ParamField>

<ParamField path="sample_rate" type="int" default="None">
  Sample rate of the incoming audio in Hz. If `None`, uses the pipeline's input
  sample rate.
</ParamField>

<ParamField path="vad_force_turn_endpoint" type="bool" default="True">
  When `True`, Pipecat's turn strategies end the user's turn and a VAD stop asks
  Deepdub to finalize the transcript right away. When `False`, Deepdub's
  endpoint detection ends the turn.
</ParamField>

<ParamField path="should_interrupt" type="bool" default="True">
  Whether the user speaking interrupts the bot, when Deepdub detects turns.
</ParamField>

<ParamField path="settings" type="DeepdubSTTService.Settings" default="None">
  Runtime-updatable settings. See [Settings](#settings) below.
</ParamField>

<ParamField path="ttfs_p99_latency" type="float" default="0.35">
  P99 latency from speech end to final transcript, in seconds, used by turn
  strategies. Measure your own deployment with
  [stt-benchmark](https://github.com/pipecat-ai/stt-benchmark) and pass the
  result.
</ParamField>

### Settings

Runtime-configurable settings passed via the `settings` constructor argument using
`DeepdubSTTService.Settings(...)`. They can be updated mid-conversation with
`STTUpdateSettingsFrame`; a change reconnects the stream.

| Parameter               | Type                | Default     | Description                                                                         |
| ----------------------- | ------------------- | ----------- | ----------------------------------------------------------------------------------- |
| `model`                 | `str`               | `"stt-egf"` | Deepdub STT model.                                                                  |
| `language`              | `str \| None`       | `None`      | `"en"` or `"he"`. `None` lets Deepdub detect the language of each utterance.        |
| `language_hints_strict` | `bool \| None`      | `None`      | Recognize only `language`, instead of preferring it.                                |
| `context_terms`         | `list[str] \| None` | `None`      | Words and names to recognize reliably, such as product names.                       |
| `context_text`          | `str \| None`       | `None`      | Background text about the conversation.                                             |
| `max_endpoint_delay_ms` | `int \| None`       | `None`      | Longest wait after speech stops before Deepdub reports an endpoint, 500 to 3000 ms. |
| `client_reference_id`   | `str \| None`       | `None`      | Your own identifier for the session.                                                |

## Usage

```python
import os

from pipecat.pipeline.pipeline import Pipeline
from pipecat_deepdub import DeepdubSTTService

stt = DeepdubSTTService(
    api_key=os.getenv("DEEPDUB_API_KEY"),
    settings=DeepdubSTTService.Settings(context_terms=["Deepdub"]),
)

pipeline = Pipeline(
    [
        transport.input(),
        stt,
        user_aggregator,
        llm,
        tts,
        transport.output(),
        assistant_aggregator,
    ]
)
```

## Notes

- **Audio format**: The service sends 16-bit mono PCM at the pipeline's input rate.
- **Languages**: English and Hebrew.

## Compatibility

Tested with Pipecat 1.17.0. See the [source
repository](https://github.com/deepdub-ai/pipecat) for the latest tested version and
changelog.
