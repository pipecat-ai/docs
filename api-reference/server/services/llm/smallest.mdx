## Overview

`SmallestLLMService` provides access to Smallest AI's Electron model through the OpenAI-compatible chat completions endpoint of the Waves API. It inherits from `OpenAILLMService` and supports streaming responses, function calling, and context management.

## Installation

```bash
uv add "pipecat-ai[smallest]"
```

## Prerequisites

1. **Smallest AI Account**: Sign up at [Smallest AI](https://www.smallest.ai/)
2. **API Key**: Generate an API key from your account dashboard

### Required Environment Variables

- `SMALLEST_API_KEY`: Your Smallest AI API key for authentication

### Settings

Runtime-configurable settings passed via the `settings` constructor argument using `SmallestLLMService.Settings(...)`. These can be updated mid-conversation with `LLMUpdateSettingsFrame`. See [Service Settings](/pipecat/fundamentals/service-settings) for details.

This service uses the same settings as `OpenAILLMService`. See [OpenAI LLM Settings](/api-reference/server/services/llm/openai#settings) for the full parameter reference. The default `model` is `"electron"`.

## Usage

### Basic Setup

```python
import os
from pipecat.services.smallest.llm import SmallestLLMService

llm = SmallestLLMService(
    api_key=os.getenv("SMALLEST_API_KEY"),
    settings=SmallestLLMService.Settings(model="electron"),
)
```

### With Custom Settings

```python
from pipecat.services.smallest.llm import SmallestLLMService

llm = SmallestLLMService(
    api_key=os.getenv("SMALLEST_API_KEY"),
    settings=SmallestLLMService.Settings(
        model="electron",
        temperature=0.7,
        max_completion_tokens=1024,
    ),
)
```

## Notes

- **Developer messages**: Electron doesn't support the `developer` role, so the service sends `developer`-role messages as `user` messages.
