## Overview

`PerplexityAgentHttpLLMService` provides access to Perplexity's Agent API, which answers with web search using models from Perplexity and other providers. It inherits from `OpenAIResponsesHttpLLMService`, so streaming, function calling, and context management work as they do on the [OpenAI Responses](/api-reference/server/services/llm/openai-responses) page.

## Installation

To use Perplexity services, install the required dependencies:

```bash
uv add "pipecat-ai[perplexity]"
```

## Prerequisites

### Perplexity Account Setup

Before using Perplexity LLM services, you need:

1. **Perplexity Account**: Sign up at [Perplexity](https://www.perplexity.ai/)
2. **API Key**: Generate an API key from your account dashboard
3. **Model or Preset Selection**: Choose a model, a preset, or both

### Required Environment Variables

- `PERPLEXITY_API_KEY`: Your Perplexity API key for authentication

## Configuration

```python
from pipecat.services.perplexity.llm import PerplexityAgentHttpLLMService
```

<ParamField path="api_key" type="str" default="None">
  Perplexity API key for authentication.
</ParamField>

<ParamField path="base_url" type="str" default="https://api.perplexity.ai/v1">
  Base URL for Perplexity API endpoint.
</ParamField>

<ParamField
  path="settings"
  type="PerplexityAgentHttpLLMService.Settings"
  default="None"
>
  Runtime-configurable settings. See [Settings](#settings) below.
</ParamField>

Other constructor arguments, such as `retry_on_timeout`, are those of `OpenAIResponsesHttpLLMService`.

### Settings

Runtime-configurable settings passed via the `settings` constructor argument using `PerplexityAgentHttpLLMService.Settings(...)`. These can be updated mid-conversation with `LLMUpdateSettingsFrame`. See [Service Settings](/pipecat/fundamentals/service-settings) for details.

This service adds the following to the settings of `OpenAIResponsesHttpLLMService` (see [OpenAI Responses Settings](/api-reference/server/services/llm/openai-responses#settings)). The default `model` is `"openai/gpt-5.6-luna"`.

| Parameter    | Type          | Default | Description                                                                                                                                                                                                                                                                              |
| ------------ | ------------- | ------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `preset`     | `str \| None` | `None`  | Perplexity preset that sets the model, its instructions, its search budget, and how much it reasons: `"fast"`, `"low"`, `"medium"`, `"high"`, or `"xhigh"`. `model` replaces the preset's model; set `model=None` to use the preset's. At least one of `model` and `preset` must be set. |
| `web_search` | `bool`        | `True`  | Whether to offer the `web_search` tool on every request, alongside any tools from the context. A preset searches the web whatever this is set to.                                                                                                                                        |
| `max_steps`  | `int \| None` | `None`  | Maximum number of search and reasoning steps per response. `None` uses Perplexity's default.                                                                                                                                                                                             |

Raises `ValueError` when the constructor settings leave neither `model` nor `preset`. A runtime update that leaves neither pushes an `ErrorFrame`.

With neither `preset` nor `reasoning` set, each request sends the `"fast"` preset, Perplexity's lowest-latency setup, and the first request for each model logs it. With `use_provider_thinking_default` set to `True`, no preset is sent.

## Usage

### Basic Setup

```python
import os
from pipecat.services.perplexity.llm import PerplexityAgentHttpLLMService

llm = PerplexityAgentHttpLLMService(
    api_key=os.getenv("PERPLEXITY_API_KEY"),
    settings=PerplexityAgentHttpLLMService.Settings(
        system_instruction="You are a helpful assistant.",
    ),
)
```

### With a Preset

```python
llm = PerplexityAgentHttpLLMService(
    api_key=os.getenv("PERPLEXITY_API_KEY"),
    settings=PerplexityAgentHttpLLMService.Settings(
        model=None,
        preset="medium",
        max_steps=3,
    ),
)
```

## Notes

- **Citations**: Answers can include citation markers such as `[1]`.
- **Anthropic models**: Models from Anthropic need `max_completion_tokens` set in the settings.

  `PerplexityAgentHttpLLMService` instead. Perplexity has ended support for the
  Sonar chat completions API that `PerplexityLLMService` uses.
</Warning>
