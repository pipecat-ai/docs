## Overview

`SpragLLMService` provides chat completion capabilities using [Sprag](https://sprag.ai)'s OpenAI-compatible API.

## Installation

This is a community-maintained package distributed separately from `pipecat-ai`.

```bash
uv add pipecat-sprag
```

## Prerequisites

### Sprag Account Setup

Before using Sprag LLM services, you need:

1. **Sprag Account**: Sign up at [sprag.ai](https://sprag.ai/auth/signup)
2. **API Key**: Generate an API key in the [Sprag app](https://sprag.ai/app/api-keys)

### Required Environment Variables

- `SPRAG_API_KEY`: Your Sprag API key. May be passed directly via the `api_key` constructor argument instead.

## Configuration

<ParamField path="api_key" type="str" default="None">
  Sprag API key. Falls back to the `SPRAG_API_KEY` environment variable.
</ParamField>

<ParamField path="base_url" type="str" default="https://api.sprag.ai/v1">
  Sprag API base URL.
</ParamField>

<ParamField path="default_headers" type="Mapping[str, str]" default="None">
  Extra headers sent with every request.
</ParamField>

<ParamField path="settings" type="SpragLLMService.Settings" default="None">
  Runtime-configurable settings. The model defaults to `"symphony"`.
</ParamField>

<Note>
  `SpragLLMService.Settings` inherits from `OpenAILLMService.Settings`. See the
  [source repository](https://github.com/sprag-ai/pipecat-sprag) for the
  authoritative, up-to-date list of settings.
</Note>

## Usage

```python
from pipecat_sprag.llm import SpragLLMService

llm = SpragLLMService(
    settings=SpragLLMService.Settings(
        system_instruction="You are a helpful assistant in a voice conversation.",
    ),
)
```

```python
pipeline = Pipeline([
    transport.input(),
    stt,
    user_aggregator,
    llm,
    tts,
    transport.output(),
    assistant_aggregator,
])
```

## Compatibility

Tested with Pipecat v1.12.0 (`pipecat-ai>=1.8,<2`). Check the [source repository](https://github.com/sprag-ai/pipecat-sprag) for the latest tested version and changelog.
