## Overview

`GmicloudLLMService` runs any text model in [GMI Cloud](https://www.gmicloud.ai)'s
catalog, GLM, DeepSeek, Gemini, Qwen and more, behind GMI Cloud's
OpenAI-compatible chat completions endpoint. It extends Pipecat's
`OpenAILLMService`, so it supports streaming responses and function calling.

The default model, `zai-org/GLM-5.3-Flash`, reasons before it answers, and its
reasoning tokens count against the completion budget. The service therefore
defaults `max_completion_tokens` to 1000 and surfaces the model's reasoning as
Pipecat thought frames (`LLMThoughtStartFrame` / `LLMThoughtTextFrame` /
`LLMThoughtEndFrame`) instead of silently dropping it.

The full model list is in
[MODELS.md](https://github.com/Jayanng/pipecat-gmicloud-llm/blob/Master/MODELS.md)
in the source repository. It is a snapshot from 2026-11-26, 71 models, and the
catalog changes, so check the live list before relying on a specific model id.

## Installation

This is a community-maintained package distributed separately from `pipecat-ai`:

```bash
uv add pipecat-gmicloud-llm
```

## Prerequisites

### GMI Cloud Account Setup

1. **GMI Cloud account**: sign up at [GMI Cloud](https://www.gmicloud.ai/)
2. **API key**: create a key in the [GMI Cloud console](https://console.gmicloud.ai/)

### Required Environment Variables

- `GMI_CLOUD_API_KEY`: your GMI Cloud API key, passed to the `api_key` constructor argument.

## Configuration

<ParamField path="api_key" type="str" required>
  GMI Cloud API key for authentication.
</ParamField>

<ParamField path="base_url" type="str" default="https://api.gmi-serving.com/v1">
  GMI Cloud OpenAI-compatible base URL.
</ParamField>

<ParamField path="model" type="str" default="zai-org/GLM-5.3-Flash">
  Model identifier to use. Any model id from GMI Cloud's `/v1/models` list.
  Prefer setting it through `settings` instead of this direct argument.
</ParamField>

<ParamField path="settings" type="GmicloudLLMService.Settings" default="None">
  Runtime-configurable settings. See [Settings](#settings) below.
</ParamField>

### Settings

Runtime-configurable settings passed via the `settings` constructor argument
using `GmicloudLLMService.Settings(...)`.

| Setting                 | Default                   | Description                                                          |
| ----------------------- | ------------------------- | -------------------------------------------------------------------- |
| `model`                 | `"zai-org/GLM-5.3-Flash"` | Any GMI Cloud text model id.                                         |
| `temperature`           | model default             | Sampling temperature.                                                |
| `top_p`                 | model default             | Nucleus sampling probability.                                        |
| `max_tokens`            | unset                     | Maximum tokens. Dropped when `max_completion_tokens` is set.         |
| `max_completion_tokens` | `1000`                    | Maximum completion tokens, including reasoning tokens.               |
| `emit_thought_frames`   | `True`                    | Emit reasoning as Pipecat thought frames. Set to `False` to drop it. |

<Note>
  GMI's support for the `developer` message role and for strict JSON-schema
  responses has not been verified, so the service converts `developer` messages
  to `user` messages and does not advertise response-schema support. See the
  [source repository](https://github.com/Jayanng/pipecat-gmicloud-llm) for the
  full list of what is and is not verified.
</Note>

## Usage

```python
import os

from pipecat_gmicloud_llm import GmicloudLLMService

llm = GmicloudLLMService(
    api_key=os.getenv("GMI_CLOUD_API_KEY"),
    settings=GmicloudLLMService.Settings(
        model="zai-org/GLM-5.3-Flash",
    ),
)

# Drop into any Pipecat pipeline:
# Pipeline([llm, transport.output()])
```

See
[`examples/ask-one-question-gmicloud.py`](https://github.com/Jayanng/pipecat-gmicloud-llm/blob/Master/examples/ask-one-question-gmicloud.py)
in the source repository for the full working version, which prints the
streamed reply and the thought frames. In a voice agent, put the service in
the pipeline next to your STT and TTS services.

Switching models is one setting:

```python
settings=GmicloudLLMService.Settings(
    model="deepseek-ai/deepseek-v4.1-flash-1017",
)
```

Function calling works through Pipecat's OpenAI adapter. Register tools in the
`LLMContext` as `FunctionSchema` objects with handlers, or with
`llm.register_function(...)`, exactly as with any OpenAI-compatible Pipecat LLM
service. See the [source
repository](https://github.com/Jayanng/pipecat-gmicloud-llm) for a complete
function calling example.

## Compatibility

Tested with Pipecat v1.17.0 (`pipecat-ai`). Check the [source
repository](https://github.com/Jayanng/pipecat-gmicloud-llm) for the latest tested
version and changelog.
