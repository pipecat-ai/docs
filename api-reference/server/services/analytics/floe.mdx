## Overview

`pipecat-floe` isn't only three model services — it's a **cost surface** for a
voice agent. Every LLM, STT, and TTS call routed through Floe is metered per call
on one balance and lands on a single ledger, and a pre-call spend cap on the Floe
agent bounds the whole run. One key, one budget, one place to see what a
conversation cost — no separate metering vendor, no per-leg reconciliation.

This is the same package documented under
[LLM](/api-reference/server/services/llm/floe),
[STT](/api-reference/server/services/stt/floe), and
[TTS](/api-reference/server/services/tts/floe) — this page covers its
cost/observability role. For a **local, no-account** hard stop that prices legs
in-process and cuts a turn before it crosses your ceiling, see the companion
[floe-guard](/api-reference/server/services/analytics/floe-guard) processor;
`pipecat-floe` here is the **server-side metered** counterpart — hosted ledger
plus enforced caps.

## Installation

This is a community-maintained package distributed separately from `pipecat-ai`:

```bash
uv add pipecat-floe
```

## What you get

- **Per-call cost.** Each call returns Floe's cost header (`X-Floe-Cost-USDC`), so
  every LLM / STT / TTS turn is priced individually.
- **One unified ledger.** LLM + STT + TTS on one `FLOE_API_KEY` settle to the same
  balance — the full per-conversation cost without joining across vendors.
- **Pre-call spend caps.** A cap on the agent (dashboard or
  `PUT /v1/agents/spend-limit`) stops a run before it crosses your ceiling —
  across all three legs together.
- **Task-scoped budgets.** Pass `task_id=` (LLM / TTS) to tag calls with an
  `X-Floe-Task-Id` header so a per-task budget can bound one conversation.
- **BYOK or keyless.** Meter your own vendor key (`provider_key=`, fee-only) or
  let Floe manage the keys — the cost view is identical either way.

## Usage

```python
import os
from pipecat_floe import FloeSTTService, FloeLLMService, FloeTTSService
from pipecat.pipeline.pipeline import Pipeline

oai = os.environ["OPENAI_API_KEY"]                          # BYOK (optional)
stt = FloeSTTService()                                       # keyless streaming STT
llm = FloeLLMService(model="openai/gpt-4o-mini", provider_key=oai, task_id="call-42")
tts = FloeTTSService(model="openai/tts-1", voice="alloy", provider_key=oai, task_id="call-42")

# Drop stt / llm / tts into a Pipecat Pipeline. Every call meters on one Floe
# balance; view per-call cost and set caps at dev-dashboard.floelabs.xyz.
pipeline = Pipeline([stt, llm, tts])
```
