## Overview

`HumeAudioClassifier` answers [classifier questions](/api-reference/server/classifiers/overview) about a clip of audio through Hume's Audio Decisions API. Hume hears the clip, and reads the state as the clip's context, such as who is speaking and what they said. All the questions about one clip go to Hume in one request. Its probabilities estimate the share of human raters who would give each answer.

A `HumeAudioClassifier` asks through a `HumeAudioDecisionsClient`, which holds the HTTP/2 connection, adds the auth header, retries when Hume is busy, and counts tokens. Build the classifier with an API key to give it a client of its own, or pass a `HumeAudioDecisionsClient` to share one connection between several classifiers.

## Installation

```bash
uv add "pipecat-ai[hume]"
```

## Prerequisites

A Hume API key, usually set as an environment variable:

```bash
HUME_API_KEY=...
```

## Usage

### Basic Usage

Every call needs exactly one clip in `inputs`. A call without one raises `ClassifierError`.

```python
import os

from pipecat.classifiers.base_classifier import ClassifierAudio, YesNoQuestion
from pipecat.classifiers.hume.audio_decisions.classifier import HumeAudioClassifier

classifier = HumeAudioClassifier(api_key=os.getenv("HUME_API_KEY"))

clip = ClassifierAudio(audio=pcm_bytes, sample_rate=16000)  # 5 seconds to 5 minutes
results = await classifier.yes_no(
    "A caller on the phone.",
    {"angry": YesNoQuestion(instructions="Does the caller sound angry?")},
    inputs=[clip],
)
results["angry"].probability
```

### Reading How the User Sounded

Pass the classifier to a [`PerceptionReader`](/api-reference/server/expressive/overview#perceptionreader), which cuts a clip of the user's speech each time they stop speaking and sets the answers as the transcription's `perception`.

### Sharing a Client

Several classifiers can share one `HumeAudioDecisionsClient`, and with it one connection pool and one token count:

```python
from pipecat.classifiers.hume.audio_decisions.client import HumeAudioDecisionsClient

client = HumeAudioDecisionsClient(api_key=os.getenv("HUME_API_KEY"))
first = HumeAudioClassifier(client=client)
second = HumeAudioClassifier(client=client)
```

A client the classifier created is closed in the classifier's `cleanup()`. A shared client is left open, so close it yourself with `await client.close()` when every classifier using it is done.

### Opening the Connection Early

`setup()` opens the connection to Hume ahead of the first question. Components that own a classifier, such as `PerceptionReader`, call it for you. If the connection cannot be opened at setup, a warning is logged and the first question opens it instead.

## HumeAudioClassifier Properties

| Property            | Type                       | Description                                                 |
| ------------------- | -------------------------- | ----------------------------------------------------------- |
| `client`            | `HumeAudioDecisionsClient` | The client this classifier asks through.                    |
| `supports_audio`    | `bool`                     | Always `True`: Hume hears audio.                            |
| `min_audio_secs`    | `float`                    | `5.0`: the shortest clip Hume hears.                        |
| `max_audio_secs`    | `float`                    | `300.0`: the longest clip Hume hears.                       |
| `audio_sample_rate` | `int`                      | `16000`: clips are resampled to 16 kHz before they're sent. |

### Properties

### Methods

#### connect

```python
await client.connect()
```

Opens the connection to Hume with a lightweight request that also checks the key. It counts toward the rate limit like any request. It connects once: a client shared by several classifiers is connected by each of them, and only the first call sends anything. Raises `ClassifierError` if Hume could not be reached or refused the request.

#### close

```python
await client.close()
```

Closes the connection pool.

## Metrics

After every call, a `HumeAudioClassifier` reports the time it took as `ProcessingMetricsData` and the input tokens used as `LLMUsageMetricsData` through its [`on_metrics`](/api-reference/server/classifiers/overview#on_metrics) event.

## Notes

- **Context**: the state is sent to Hume as the clip's context, as text or as JSON for structured state. Hume reads at most 1000 characters of it, so a longer state keeps its last 1000 characters. The limit is available as `HUME_MAX_CONTEXT` in `pipecat.classifiers.hume.audio_decisions.classifier`.
- **Audio**: a call takes exactly one clip in `inputs`; any other number raises `ClassifierError`. Clips are sent as 16 kHz mono WAV, which is how the model hears them.
- **Images**: `HumeAudioClassifier` cannot see images. Passing some raises `ClassifierError`.
- **Errors**: a rejected request, a busy Hume after every retry, an unreachable server, or a reply missing an answer all raise `ClassifierError`.
