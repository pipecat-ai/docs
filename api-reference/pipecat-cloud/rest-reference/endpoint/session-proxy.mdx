Send HTTP requests to endpoints defined in your running bot. Supports `GET`, `POST`, `PUT`, `PATCH`, `DELETE`, `OPTIONS`, and `HEAD` methods.

## Request Headers

Headers are forwarded to your bot with these exceptions:

- `host` - Excluded
- `content-length` - Excluded
- `authorization` - Excluded (authentication is handled by the API gateway)
- `accept-encoding` - Replaced with `identity`. Callers receive responses uncompressed, so your bot doesn't need to compress them (a `gzip` or `deflate` response is decompressed for the caller)

## Redirects

A redirect from your bot is followed only if it stays on your bot's own server, such as the redirect FastAPI sends to add a trailing slash. Up to 5 redirects are followed per request.

A redirect anywhere else, or a longer chain, returns `502` to the caller. To send a caller elsewhere, return the URL in your response body.

<Note>
  Requires base image version `0.1.2` or later. See the [Session API
  guide](/pipecat-cloud/guides/session-api) for setup instructions and examples.
</Note>
