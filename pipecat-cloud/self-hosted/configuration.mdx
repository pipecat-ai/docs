The region package installs with sensible defaults; the values below are the ones a production region typically sets. Your values file should contain only what the package cannot know about your cluster — never image references or versions.

## Region identity

{/* global.regionKey, workloadsNamespace.{create,name} */}

## Broker

{/* valkey.enabled false + externalBroker.* */}

## Log store

{/* logging.enabled (default off), logging.external.* and the operator/agent mirrors */}

## WebSocket exposure

{/* wsExposure.mode none|ingress|httpRoute */}

## Replicas and availability

{/* region-agent.replicaCount, pipecat-bot-starter.replicaCount */}

## Agent pod settings

{/* botPodDnsConfig ndots; scheduling overlay */}

## Image pull credentials

{/* registry.pullSecret.managed */}

## Diagnostics

{/* region-agent.supportBundle.enabled */}
