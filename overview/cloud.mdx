Pipecat Cloud and Pipecat Enterprise are hosted infrastructure for deploying and scaling Pipecat agents in production. Both share one control plane, CLI, and API; they differ in where your agents run.

<CardGroup cols={2}>
  <Card title="Pipecat Cloud" icon="cloud" href="/pipecat-cloud/introduction">
    Multi-tenant and fully managed. Your agents run in Daily-hosted regions and
    Daily operates everything.
  </Card>
  <Card
    title="Pipecat Enterprise"
    icon="building"
    href="/pipecat-cloud/enterprise/overview"
  >
    Single-tenant and hybrid. Pipecat Cloud stays the control plane; your agents
    run in a Kubernetes cluster in your VPC.
  </Card>
</CardGroup>

Start with the [introduction](/pipecat-cloud/introduction) to compare the two, see what carries over between them, and deploy your first agent.
